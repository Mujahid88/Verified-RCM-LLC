Our complete oncology guide

Oncology ICD-10 coding: neoplasm specificity, laterality, and sequencing.

Oncology denials rarely start with the wrong drug or the wrong CPT code, they start with the diagnosis line. A missing laterality digit, a malignant code billed after the tumor is gone, or a chemotherapy encounter coded with the neoplasm listed first instead of second are three of the most common, entirely preventable reasons an oncology claim comes back. This guide covers primary malignancy coding by site with laterality, the C77–C79 secondary-neoplasm rules and exactly when a treated primary becomes a Z85 history code instead, the Z51.11/Z51.12 sequencing rule for chemotherapy and immunotherapy encounters, and when a D37–D48 uncertain-behavior code is the correct answer instead of a malignant one.

Key takeaways

  • Laterality is billable, not optional, on breast and lung primaries. C50 (breast) and C34 (lung/bronchus) both carry right, left, and unspecified sixth characters, verified live against the FY2026 ICD-10-CM code set, and an unspecified-side code where the pathology names a side is a specificity gap payers can catch automatically.
  • A treated primary only becomes a Z85 history code once it's gone and nothing is still being done about it. If any treatment is still directed at the primary site, including adjuvant therapy, it's coded as an active malignancy, not history, regardless of how the patient is described clinically.
  • Z51.11 or Z51.12 leads the claim when the visit is chiefly for drug administration. The malignancy code is secondary. Since FY2024 the guideline word changed from "solely" to "chiefly," widening when the Z51 code can be sequenced first.
  • D37–D48 uncertain-behavior codes require a pathology report that actually says "uncertain behavior." They are not a stand-in for an unworked-up or unspecified malignancy, and one of the two most common oncology diagnosis denials is exactly this substitution.

Primary malignant neoplasm coding by site: specificity and laterality

Oncology's ICD-10 chapter (C00–C96 for malignant primaries) rewards exactly the kind of specificity most other specialties only ask for occasionally. Three of the highest-volume sites illustrate the pattern, and all three code families below were pulled and confirmed live against the FY2026 ICD-10-CM code set.

Primary malignancy coding by site, verified against the FY2026 ICD-10-CM code set. All codes below confirmed billable for HIPAA transactions.
SiteCategory headerLaterality axis?Example billable codes
BreastC50 Malignant neoplasm of breastYes, right/left/unspecified, plus separate female/male branchesC50.911 unsp site, right female breast · C50.912 unsp site, left female breast · C50.919 unsp site, unspecified female breast · C50.A1/C50.A2 inflammatory carcinoma, right/left
Bronchus and lungC34 Malignant neoplasm of bronchus and lungYes, right/left/unspecified at the sixth characterC34.11 upper lobe, right · C34.12 upper lobe, left · C34.31 lower lobe, right · C34.90 unspecified part, unspecified bronchus/lung
ColonC18 Malignant neoplasm of colonNo laterality axis, specificity is by segment insteadC18.0 cecum · C18.2 ascending colon · C18.7 sigmoid colon · C18.9 colon, unspecified (avoid as primary when a segment is documented)

The pattern to take from this table: not every neoplasm category has a laterality dimension, and assuming one does (or doesn't) without checking the specific category is how specificity errors happen in both directions. Breast and lung both split at the sixth character into right, left, and unspecified, and breast further splits by quadrant (upper-outer, upper-inner, lower-outer, lower-inner, central, axillary tail, and overlapping) before laterality is even applied, which is 86 total codes in the C50 category alone. Colon has no side to document at all; a coder reaching for laterality on a colon primary is solving a problem that category doesn't have, while missing that the real specificity axis there is the bowel segment. The operative note or pathology report is the source for both: the surgeon's or pathologist's stated side and site, not an assumption carried over from the referral.

Unspecified-site and unspecified-laterality codes exist in every category above and are billable, C50.919 and C34.90 both validate as HIPAA-billable, but billable is not the same as defensible. A payer's claims-edit logic increasingly flags an unspecified-side breast or lung code against a claim that also carries a laterality-specific CPT or HCPCS code (a right mastectomy, a left lobectomy) as an internal inconsistency worth a medical-record request, even when it doesn't hard-deny outright. The fix is upstream of coding: the pathology report and operative note need to state the side and site in the first place, and the coder needs to read past the referral diagnosis to the actual specimen report before finalizing the code.

Secondary and metastatic neoplasm coding, and when the primary becomes "history of"

Metastatic disease coding is where oncology claims most often go wrong, because it requires tracking two separate facts at once: where the cancer started, and where it currently is or has been treated. ICD-10-CM handles this with a dedicated secondary-neoplasm chapter, C77–C79, that exists specifically to code a metastasis independently of its primary.

Secondary (metastatic) neoplasm coding by site, verified against the FY2026 ICD-10-CM code set. All codes below confirmed billable for HIPAA transactions.
CategoryCoversExample billable codes
C77Secondary and unspecified malignant neoplasm of lymph nodesC77.3 axilla and upper limb nodes · C77.9 lymph node, unspecified
C78Secondary malignant neoplasm of respiratory and digestive organsC78.00 unspecified lung · C78.7 liver and intrahepatic bile duct
C79Secondary malignant neoplasm of other and unspecified sitesC79.11 bladder · C79.31 brain · C79.51 bone · C79.9 unspecified site (avoid as primary metastatic code when the site is documented)

A metastasis is always coded from these categories regardless of the primary's own histology, a breast primary that has spread to bone is coded as the breast primary plus C79.51, not as a bone primary. Sequencing depends on what the encounter is actually for: if the visit addresses the primary and secondary sites together, or the primary is the chief concern, the primary is sequenced first with the metastatic code(s) as additional diagnoses. If the encounter's treatment is directed specifically at the metastatic site, a bone-directed radiation course for a known osseous metastasis, for example, the secondary-site code is sequenced first, with the primary (or its Z85 history code, if it qualifies) as an additional diagnosis. Getting this backward is a documentation-support problem as much as a coding one: the sequencing has to match what the note says the visit was for, not a default habit.

Code as active primary when
  • Any treatment, surgical, medical, or radiation, including adjuvant therapy, is still directed at the primary site, or the primary has not been fully excised or eradicated.
  • There is any current evidence of the primary malignancy, even if the patient is also receiving treatment for a metastasis elsewhere.
Switch to Z85 "history of" only when
  • The primary has been surgically removed or otherwise eradicated, and no further treatment is directed to that site, and there is no evidence of any existing primary malignancy there. All three conditions have to be true at once, a Z85 code used while any one of them isn't true is a coding error that understates disease burden, not a documentation shortcut.
  • If disease later recurs, extends, or is found to have spread, the history code is dropped for an active recurrence or secondary-site code, a Z85 code and an active malignancy code for the same site are never both correct at the same time.

The category to know for "history of" coding is Z85, Personal history of malignant neoplasm, which we confirmed is organized by the primary's original site rather than as one generic code. Z85.3 (personal history of malignant neoplasm of breast) and Z85.118 (personal history of other malignant neoplasm of bronchus and lung) both validate as billable; note that the three-character site headers under Z85 (like Z85.11, bronchus and lung generally) are category headers only and are not themselves billable, the claim needs the fourth- or fifth-character child code that specifies carcinoid versus other histology.

Sequencing chemotherapy and immunotherapy encounters

This is the single most common sequencing error our reviewers see on oncology infusion claims: the malignancy code billed first, with the Z51 encounter code (if used at all) listed second or omitted. The rule runs the other way for treatment-administration visits.

When the reason for the encounter is chiefly the administration of chemotherapy, immunotherapy, or radiation therapy to treat a malignancy, the applicable Z51 code is sequenced as the first-listed diagnosis, and the malignancy being treated is reported as a secondary diagnosis. The two codes at issue for drug administration:

  • 1Z51.11, Encounter for antineoplastic chemotherapy. First-listed when the visit is chiefly for chemotherapy infusion or injection, with the treated malignancy (or its C77–C79 metastatic code, if that's the site being treated) reported second.
  • 2Z51.12, Encounter for antineoplastic immunotherapy. Same first-listed logic, for checkpoint inhibitors, monoclonal antibodies, and other immunotherapy agents administered for an oncologic indication.

Both codes validated live as HIPAA-billable against the FY2026 code set. A meaningful wording change took effect with the FY2024 ICD-10-CM Official Guidelines and remains current: the guideline previously required the encounter to be "solely" for chemotherapy administration before Z51.11 could lead, which excluded a visit where anything else was also addressed. That word was replaced with "chiefly," which means Z51.11 or Z51.12 can still be sequenced first as long as drug administration was the main reason for the visit, even if the clinician also manages an unrelated or related condition at the same encounter. Practices whose coding staff or scrubber rules still encode the older "solely" standard are under-using the Z51 codes on visits that now qualify.

⚠️ This sequencing rule is stated with confidence based on the FY2026 ICD-10-CM Official Guidelines for Coding and Reporting (Section I.C.2.e, chemotherapy/immunotherapy for treatment of neoplasm) as summarized consistently across multiple current coding-education sources reviewed for this build (AAPC Knowledge Center and Healthicity's ICD-10 guideline series, among others); the CMS-hosted guideline PDF itself could not be parsed directly during this build (the retrieved file returned as unreadable binary rather than extractable text), so the exact guideline wording was not confirmed against the primary CMS/NCHS document character-for-character. Pull the current FY guidelines PDF directly and confirm Section I.C.2.e before finalizing a coding policy or scrubber rule against this rule.

One more sequencing wrinkle worth flagging: this Z51-first rule applies specifically to encounters for administering treatment. A visit for a surgical procedure to treat the malignancy, or an E/M visit to manage a treatment complication rather than to administer treatment, follows different sequencing logic, the malignancy (or the complication code, per the guidelines on complications of care) leads instead. Don't apply the Z51-first rule reflexively to every oncology encounter; it's specific to the chemotherapy/immunotherapy/radiation administration visit itself.

Neoplasm of uncertain behavior: when D37–D48 is the right answer

Categories D37 through D48 cover neoplasms of uncertain behavior, a distinct clinical category from malignant, benign, or unspecified, and one of the most consistently misused code ranges in oncology billing.

Neoplasm of uncertain behavior, selected categories verified against the FY2026 ICD-10-CM code set. All codes below confirmed billable for HIPAA transactions.
CategoryCoversExample billable codes
D37Uncertain behavior, oral cavity and digestive organsD37.4 colon · D37.1 stomach · D37.5 rectum
D48Uncertain behavior, other and unspecified sitesD48.60 unspecified breast · D48.61/D48.62 right/left breast · D48.9 uncertain behavior, unspecified site (avoid as primary once a site is documented)

"Uncertain behavior" is a pathology finding, not a coder's judgment call and not a synonym for "not yet worked up." The code applies only when the pathology report itself documents that the tumor's behavior, whether it will act as benign or malignant, could not be determined at the time of examination, which happens with certain borderline ovarian tumors, some neuroendocrine neoplasms, and comparable diagnostically ambiguous specimens. It is never appropriate to use a D37–D48 code in place of an unspecified malignant code simply because the encounter note doesn't yet specify histology, and it is never appropriate to carry a D37–D48 code forward once a definitive diagnosis (malignant or benign) has been confirmed on final pathology, the definitive code replaces it going forward, on subsequent encounters, not alongside it.

This distinction matters for medical necessity as much as for accuracy: a payer's coverage policy for a diagnostic procedure often lists malignant neoplasm codes as a covered indication and treats an uncertain-behavior code differently, so substituting one for the other in either direction can produce a medical-necessity denial that has nothing to do with whether the service itself was appropriate.

Procedure-to-diagnosis crosswalk

The pattern that ties all three coding rules above together is which diagnosis code actually belongs in the primary position for a given kind of oncology encounter. This is the crosswalk our coders check first on a new oncology account.

Common oncology service types and the correct primary-diagnosis pattern.
Service or encounter typeCorrect primary diagnosis pattern
Initial diagnostic biopsy, mass of unconfirmed histologySymptom or mass code (e.g., a screening/diagnostic finding code) until pathology returns, never a malignant code assigned before confirmation, and never a D37–D48 code unless pathology specifically states uncertain behavior
Surgical resection of a confirmed primary tumorThe site- and laterality-specific malignant primary code (e.g., C50.211, C34.31) as first-listed, reflecting active disease at time of surgery
Chemotherapy or immunotherapy infusion visitZ51.11 or Z51.12 first-listed, with the treated malignancy or metastatic site code(s) as secondary
Radiation therapy administration visitZ51.0 (encounter for antineoplastic radiation therapy) first-listed, malignancy as secondary, same logic as the chemo/immunotherapy codes above
Surveillance visit, no evidence of disease, primary previously treatedThe applicable Z85 personal-history code, plus any relevant surveillance/aftercare Z code the payer's policy requires, not the original malignant code
Treatment visit directed at a known metastatic site, primary previously treated and no longer activeThe C77–C79 secondary-site code first-listed, the Z85 history code as additional, since the primary itself is no longer being treated
E/M visit for a treatment-related complication (e.g., chemotherapy-induced neutropenia)The complication code first-listed per the guidelines on complications of care, with the malignancy or Z51 status as secondary, not a routine Z51 administration code, since no drug is being given at this visit
Pro tip

Ask one question before finalizing any oncology diagnosis line: "what is today's visit actually for?" If it's drug administration, Z51 leads. If it's treatment of a known metastasis, the secondary-site code leads. If nothing is being done to the primary anymore and there's no evidence of it, the primary becomes history, not an active code. The service being billed on the claim almost always tells you the correct sequencing, the error usually comes from defaulting to whatever diagnosis code was used last visit instead of rechecking it against today's actual encounter.

The most common denial: surveillance coded as active, or active coded as surveillance

Two versions of the same underlying error account for a large share of oncology diagnosis-driven denials, and they run in opposite directions.

The surveillance-versus-active-treatment coding trap.
Error patternWhy it firesFix
Active malignant code billed on a true surveillance visitThe primary was fully treated months or years ago and the visit is a follow-up scan or labs with no evidence of disease, but the original active C-code is still on the chart and gets carried onto the claim by habitConfirm eradication status at each surveillance visit; switch to the matching Z85 code once all three "history of" conditions are actually met, and use the appropriate surveillance/screening code, not the original malignancy code, going forward
Z85 history code billed while treatment is still activeA biller defaults to "history of" once a patient is described as being in a maintenance or surveillance phase of therapy colloquially, even though a treatment (adjuvant therapy, ongoing monitoring for a known residual, etc.) is still directed at that siteConfirm with the treating oncologist's note whether treatment toward that specific site is ongoing before switching to a history code, the clinical language ("doing well," "stable") is not the test; the treatment plan is

Both versions produce the same downstream problem from opposite directions: an active code that should be history overstates ongoing disease and can trigger a medical-necessity mismatch against a service that a surveillance-only policy wouldn't cover the same way; a history code that should be active understates disease burden and can misrepresent medical necessity for a service that requires evidence of active malignancy to be covered at all. Neither is a coder's guess to make from the visit type alone, both require confirming, encounter by encounter, exactly what the treatment plan says is happening to the primary site right now.

Frequently asked questions

When does a treated primary cancer become a "history of" code instead of an active malignancy code?

A Z85 personal history code replaces the active malignancy code only when the primary site has been excised or eradicated, no further treatment is directed to that site, and there is no evidence of any existing primary malignancy there. If any treatment toward the primary site is still underway, including adjuvant therapy, the primary is still coded as active, not as history. If the tumor later extends, recurs, or spreads, a recurrence or a new secondary-site code applies instead of the history code; a history code is never used while disease is present.

Which diagnosis code goes first when the encounter is for chemotherapy or immunotherapy administration?

When the encounter is chiefly for the administration of chemotherapy, immunotherapy, or radiation therapy to treat a malignancy, the encounter code from category Z51 is sequenced first: Z51.11 for chemotherapy or Z51.12 for immunotherapy. The malignancy being treated is reported as a secondary diagnosis. Since FY2024, the guideline uses "chiefly" rather than "solely," so the Z51 code can still lead even if another condition is also addressed at the same visit, as long as drug administration was the main reason for the encounter.

Do we need a laterality digit on every cancer diagnosis code?

Not every neoplasm category has a laterality axis, but where one exists, payers expect it. Breast (C50) and lung/bronchus (C34) both split into right, left, and unspecified at the sixth character, and an unspecified-side code on a claim where the operative or pathology report names a side is a specificity gap most payers' edits will catch. Colon cancer (C18) has no laterality axis at all; specificity there comes from the segment (cecum, ascending, sigmoid, and so on), not a side.

When is it appropriate to use a neoplasm of uncertain behavior code instead of a malignant code?

A code from category D37-D48 is appropriate only when the pathology report itself states the behavior is uncertain or borderline, meaning the pathologist could not determine at the time of examination whether the tumor is benign or malignant. It is not a placeholder for a diagnosis that simply hasn't been worked up yet, and it is not interchangeable with an unspecified malignant code. Once a definitive malignant or benign diagnosis is confirmed, the uncertain-behavior code is replaced, not carried forward alongside it.
