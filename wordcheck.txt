Our complete pulmonary medicine guide Pulmonology modifiers: 25, 26/TC, 59, and 52 explained. Four modifiers carry almost all of the modifier-driven revenue risk in pulmonology, and each one gets misapplied for a different structural reason: 25 on a visit that doesn't clear the documentation bar, 26/TC on a code that was never eligible to split in the first place, 59 or an X-modifier on an edit that no modifier can override, and 52 on a scope that payers and specialty societies don't actually consider reduced. This guide works through each one with the specific test - the indicator value, the note requirement, the scenario - that decides whether the claim holds up. Indicator 2, 3, and 4 codes are already stand-alone professional-only, technical-only, or global-only - appending 26 or TC to one of those doesn't split the fee, it denies the line. Modifier 25 needs the same documentation test whether it's riding on a PFT or a bronchoscopy. A note whose entire content is the pre-test workup for the procedure that follows doesn't clear it, regardless of which procedure it is. 59 and the X-modifiers never override an indicator-0 pair. Check the NCCI indicator for the specific pair before writing a single word of appeal justification. Modifier 52 on a trach- or ETT-route bronchoscopy is a documented controversy, not a settled shortcut. Why these four carry the weight in pulmonology Pulmonology's modifier risk concentrates on four decisions: whether an E/M billed alongside a test or procedure stands on its own, whether a diagnostic code is even eligible to split between interpretation and acquisition, whether a bundling edit can be overridden at all, and whether a study or procedure that came in short of the full code description was legitimately reduced. Get any of the four wrong and the claim usually doesn't deny outright - it either pays at the wrong rate, gets recouped on a later audit, or burns staff time on an appeal the underlying indicator value never allowed to succeed. The pillar guide covers the summary version of each; this page works the decision logic all the way through. Modifier 25: the same documentation test for every same-day service Modifier 25 reports a significant, separately identifiable E/M service billed the same day as a procedure or diagnostic test. The test doesn't change based on what the E/M accompanies - only the fact pattern payers scrutinize does. Two scenarios cover nearly all of the specialty's volume. Clears the bar New respiratory complaint worked up in full (history, exam, differential) on the same day spirometry happens to be performed. Escalating a biologic asthma regimen or titrating home oxygen based on findings that go beyond the test result itself. A separate, unrelated condition addressed at the same visit - a hypertension check alongside a scheduled PFT. Doesn't clear it A note whose entire content is "patient here for spirometry, reviewed result with patient." The pre-procedure history and physical performed solely to clear a patient for a scheduled bronchoscopy. A visit built around ordering the test itself, with no separate assessment or plan documented. Diagnostic bronchoscopy (31622) carries a 000-day global period (per aggregated CPT fee-schedule data; confirm against the CMS PFS Look-Up Tool for your locality), so the same logic that governs a same-day PFT visit governs a same-day bronchoscopy visit: the E/M has to represent work beyond what's already bundled into the procedure's own pre-service time. A physician evaluating a new symptom, managing a separate diagnosis, or reaching a treatment decision that doesn't depend on the scope findings supports 25. A visit that exists only to obtain consent and confirm the patient is fit for the procedure does not, because that work is already valued inside the procedure code. Modifier 26 and TC: the PC/TC indicator decides whether a split exists at all Before appending 26 or TC to any pulmonology diagnostic code, the question isn't "does our physician interpret this" - it's whether CMS's own PC/TC indicator for that specific code allows a split in the first place. Four indicator values govern this (Medicare Physician Fee Schedule payment policy indicators, as published by CMS and its contractors): PC/TC indicator values that apply to pulmonology diagnostic testing codes. Indicator Meaning Modifiers usable 1 Diagnostic test code with both a professional and technical component 26 and TC both valid 2 Professional-component-only code - a separate code already reports the technical side Neither - bill the base code alone for the physician's work 3 Technical-component-only code - a separate code already reports the professional side Neither - bill the base code alone for the technical work 4 Global-test-only code - no split exists; separate PC-only and TC-only codes exist elsewhere for this test Neither on this specific code Only indicator-1 codes take 26 or TC at all. Appending either modifier to an indicator-2, -3, or -4 code doesn't split the payment the way it would for an indicator-1 code - it's billed against a code that was never structured to carry that modifier, and it denies. Spirometry performed in a hospital-based pulmonary function lab is the textbook indicator-1 scenario: the pulmonologist bills 26 for reading and reporting the flow-volume tracing, the hospital bills TC for the equipment and technologist time, and the two claims are complementary rather than duplicative - provided the professional side is backed by an actual signed interpretive report, not a verbal comment or a signature on the technician's worksheet. The same split logic extends to polysomnography. When the interpreting physician isn't the entity that ran the sleep lab, split billing with 26 (physician interpretation) and TC (sleep technologist and equipment) is standard, and skipping the modifier on either side is a common cause of duplicate-service denials when both the facility and the physician bill the same code unmodified for the same study night. As with PFTs, don't assume every code in the sleep-study family carries indicator 1 - confirm the specific CPT code's own indicator before building a split-billing rule around it, and route the professional claim under the interpretation date, not the acquisition date, when the two fall on different calendar days. Pro tip Build the PC/TC indicator into the charge master, not into a coder's memory. A practice that reads studies acquired at three different hospital sites needs a code-by-code list of which PFT and sleep-study codes actually carry indicator 1, because guessing by analogy from one code to a similar-sounding one is exactly how a 26 claim ends up on a code that was never eligible to take it. 59 and the X-modifiers: only where the indicator allows it These override an NCCI Column 1/Column 2 bundling edit - but the modifier indicator attached to the specific pair decides whether an override is even possible before any documentation question comes up. An indicator of 0 means the second code is never separately payable at that session, full stop; an indicator of 1 means an override is possible, but only with documentation of a genuinely distinct service. XE Separate encounter. A distinct service performed during a separate patient encounter on the same date. XS Separate structure. The modifier that covers most defensible pulmonology unbundling - a separate, non-contiguous lobe or lung sampled in a distinct step of a bronchoscopy session. XP Separate practitioner. A distinct service performed by a different practitioner. XU Unusual non-overlapping service. The rarest of the four; use only when none of the other three, or plain 59, describes the distinction better. The specialty's clearest indicator-0 example is diagnostic bronchoscopy (31622) against a same-session biopsy or brushing code (31623, 31625) - the diagnostic exam is inherent to the biopsy that follows it, and no modifier, however well documented, changes that. Where a pair does carry indicator 1, the operative note has to independently support the distinction: a separate anatomic site, a separate session, or a separate practitioner, documented at the time of the procedure rather than reconstructed afterward to answer a denial. Reach for the specific X-modifier over generic 59 wherever it applies - it states the reason for the split directly on the claim, which is exactly what an auditor is looking for. A pattern of routine 59 use to clear edits, rather than to reflect services that were actually distinct, is one of the most reliably audited billing patterns across every specialty that does bundled procedural work, pulmonology included; payers track append rates at the practice level, not just at the claim level. Modifier 52: real reduced services, not a routine shortcut Modifier 52 reports a service reduced or eliminated at the physician's discretion, planned or recognized before or during the encounter. It applies in two documented pulmonology scenarios - and a third, frequently proposed use that the specialty's own professional society has formally pushed back on. Modifier 52 scenarios in pulmonology, and the one that isn't supported. Scenario 52 supportable? Home sleep apnea test recorded under the 6-hour minimum but still clinically interpretable Yes - applies to the commercial CPT HST codes (95800/95801/95806); Medicare's HCPCS G-codes follow their own frequency and duration documentation instead Bronchoscopy aborted before any meaningful intervention because the patient became unstable, at the physician's discretion before real work began Yes, per AABIP's own guidance - distinct from stopping mid-procedure for patient safety, which is modifier 53 Bronchoscopy performed through an existing tracheostomy or endotracheal tube instead of the upper airway No, per AABIP's position statement - an artificial airway is standard practice for the patients who need one and often adds procedural complexity rather than reducing it The trach/ETT question is worth naming specifically because it's a documented disagreement, not settled guidance. A CPT Assistant item published in August 2021 suggested applying modifier 52 to bronchoscopy performed via tracheostomy or ETT, on the theory that bypassing the upper airway reduces procedural complexity. The American Association for Bronchology and Interventional Pulmonology issued a position statement rejecting that reasoning, arguing that patients requiring an artificial airway typically carry more comorbidity and procedural risk, not less - bronchospasm, hypoxemia, bleeding, and arrhythmia risk don't go down because the upper airway was bypassed, and switching from an uncuffed to a cuffed tracheostomy tube mid-procedure adds complexity of its own. AABIP states plainly that CMS and professional respiratory societies don't support the routine application CPT Assistant's item implied. Treat that CPT Assistant guidance as contested rather than authoritative, and reserve modifier 52 for bronchoscopy that's genuinely incomplete - aborted before any meaningful intervention occurred. 52 - reduced services Provider's own choice or an anticipated limitation, before or during the service, cuts it short of the full code description. Example: HST recording under 6 continuous hours, still clinically usable. 53 - discontinued procedure Stopped mid-procedure because continuing threatens the patient's well-being - not the physician's discretionary choice. Example: bronchoscopy halted after sedation and scope insertion because of acute hypoxemia or hemodynamic instability. Do and don't Do Confirm a code's PC/TC indicator before assuming it splits with 26/TC - don't extrapolate from a similar-sounding code. Require a note that stands on its own, apart from the test or procedure order, before appending modifier 25. Check the NCCI modifier indicator for the specific pair before writing any 59 or X-modifier appeal. Reserve modifier 52 for a genuinely incomplete study or an HST under 6 hours - not a scope performed via an existing airway. Don't Don't append 26 or TC to a professional-only, technical-only, or global-only code expecting it to split the payment. Don't bill modifier 25 on a note whose entire content is the pre-test or pre-procedure workup. Don't use 59 or an X-modifier to push through an indicator-0 pair - no documentation reverses that value. Book a free claims review Frequently asked questions Does modifier 26 apply to every PFT code, or only some of them? Only some. CMS assigns every code a PC/TC indicator, and only indicator 1 (diagnostic test codes with both a professional and technical component) supports the 26/TC split at all. A code with indicator 2, 3, or 4 is already a stand-alone professional-only, technical-only, or global-only code, and appending 26 or TC to one of those denies rather than splits it. Check the specific PFT code's own indicator in the Medicare Physician Fee Schedule before assuming the whole family behaves the same way. Should we append modifier 52 to a bronchoscopy performed through a tracheostomy or ETT? No, according to the American Association for Bronchology and Interventional Pulmonology's position statement, which pushes back specifically on a 2021 CPT Assistant item that suggested it. AABIP's position is that operating through an existing airway reflects standard care and often added complexity - not a reduced service - and that CMS and professional respiratory societies don't support routine 52 use on that basis alone. Reserve modifier 52 for a bronchoscopy that's substantially incomplete, such as one aborted before any meaningful intervention because the patient became unstable; that's a different scenario from choosing to abort for safety mid-procedure, which is modifier 53. Can modifier 25 apply to an E/M billed the same day as a bronchoscopy, or only alongside PFTs? It can apply to either, because the documentation test is the same regardless of which procedure the E/M accompanies. Diagnostic bronchoscopy (31622) carries a 000-day global period, so a same-day E/M is billable with modifier 25 only when the note shows a significant, separately identifiable service beyond the pre-procedure workup and the decision to proceed - a new complaint being evaluated, a separate condition being managed, or findings that changed the treatment plan independent of the scope itself. A visit whose entire content is the pre-procedure history and physical for the bronchoscopy doesn't clear that bar, the same way a visit that's just spirometry review doesn't. Verify before billing.
