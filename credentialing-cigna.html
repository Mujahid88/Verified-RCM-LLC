Cigna credentialing: CAQH-based verification with behavioral health routed to Evernorth.

Cigna credentials nationally, with a structure similar to other large commercial payers, but with two features that make it different from a straightforward document pull. Every application starts with a pre-application eligibility call before any paperwork moves, and Cigna will verify from any of three separate documentation sources rather than insisting on one. The two things that still trip practices up are behavioral health, which is administered through Evernorth, and the assumption that credentialing approval alone means you can bill as in-network. Get the intake step right and the rest of the process is largely procedural; get it wrong and a file can sit for months without ever generating a rejection that would tell you something is off.

Key takeaways

  • The pre-application call comes first. Cigna confirms network eligibility by phone before any documentation is pulled or paperwork submitted.
  • Three intake sources are accepted. CAQH ProView, One Healthport/Medversant, or Cigna's own e-onboarding tool — pick one and keep it current.
  • Behavioral health goes through Evernorth. Mental health and substance use practitioners credential separately from the medical network.
  • Contracting is the participation step. Credentialing verifies the provider; only an executed contract creates network status.
  • Recredentialing runs on a fixed cycle. Missing it can suspend participation with little practical grace period.

How Cigna credentialing works

Cigna operates a centralised credentialing process, but it starts differently from most national commercial payers: before any document ever moves, a Cigna credentialing representative confirms by phone that the practitioner's specialty and service area actually have an open network need. Most payers surface network status passively, if at all, through a portal or a generic "we are not accepting new providers" message discovered only after a full file has already been submitted. Cigna front-loads that conversation instead, which is a genuine advantage when it works as intended and a genuine bottleneck when the call itself is hard to get scheduled or nobody on the practice side treats it as a required step.

Once eligibility is confirmed, Cigna verifies licensure, education, board certification, malpractice history and sanctions against primary sources, then presents the file to a credentialing committee. Participation requests, contracting, claims and eligibility all run through CignaforHCP.com, the payer's provider portal. As with other large commercial payers, the completeness and currency of the underlying documentation is the biggest single determinant of how quickly a file clears verification — Cigna is simply less locked into any one data source than most payers its size, because it will pull from more than one place.

The credentialing committee itself reviews files rather than rubber-stamping a verification report, which means a clean file with no flagged items can still take time simply waiting for a scheduled meeting, while a file with a genuine issue — a lapsed licence renewal, a malpractice claim history, a gap in coverage — gets pulled aside for individual discussion rather than an automatic denial. That distinction matters for how a practice should plan: a file with nothing unusual in it is mostly a waiting game once submitted correctly, while a file with something to explain is worth explaining proactively in writing rather than waiting for the committee to ask and losing a meeting cycle to the question.

Three accepted documentation sources, and the call that precedes them

Most large commercial payers verify exclusively from CAQH ProView. Cigna accepts CAQH, but it will also work from a profile maintained in One Healthport (Medversant), or from Cigna's own e-onboarding tool submitted directly through the provider portal. That flexibility helps practices that already maintain a current profile in one of the other two systems for a different payer relationship, but it also creates a specific failure mode: a practice assumes Cigna is pulling from CAQH, keeps CAQH current, and never realises the application was actually routed through e-onboarding with a document list that was never fully populated there. Confirming which source Cigna is using for a given application, in writing, before you consider the documentation step finished is the difference between a clean file and weeks of silence.

The pre-application eligibility call is worth treating as a formal step in its own right rather than a courtesy check. It exists because Cigna, like every large commercial payer, opens and closes specific specialties and service areas to new participation on an ongoing basis, and building a complete documentation file against a network that will not accept it wastes the time spent gathering it. Coming to the call with the practitioner's specialty, taxonomy, exact service address and the products being requested ready to state precisely is what keeps a five-minute confirmation from turning into a callback that sits in a queue for a week. Full detail on all three intake sources, how to prepare for the eligibility call so it doesn't become the bottleneck itself, and what to do when the call reveals a closed network, is in our CAQH, e-onboarding, and pre-application call guide.

Behavioral health credentialing through Evernorth

Behavioral health is administered by Evernorth, Cigna's health services organisation, with its own credentialing pathway, contracts and network decisions — a separate application, a separate email address (BehavioralProviderRecruitment@Evernorth.com), and a separate phone line (1-800-926-2273) from the medical process described above. Practices with both medical and behavioral practitioners run two parallel processes, and routing a therapist or psychiatrist through the medical pathway generally results in an application that stalls rather than one that is formally declined, because the medical intake system has no reason to flag a behavioral provider as misrouted; it simply sits waiting on a document review that will never happen. This is easy to get wrong precisely because "Cigna" is the name on the insurance card either way — nothing in a typical intake conversation with a new hire's front-desk paperwork flags that a licensed clinical social worker or psychiatric nurse practitioner needs an entirely different application than the physician sitting one office over. Confirming the pathway before submission avoids months of silence. Full detail on how the Evernorth application differs from Cigna's own, and the specific mistake of applying through the wrong channel, is in our behavioral health credentialing guide.

Step by step: how to do it

  1. Complete the pre-application eligibility callConfirm with Cigna that the practitioner's specialty and service area have an open network need before gathering a single document. Do this first, not in parallel with the documentation step.
  2. Choose and populate a documentation sourceCAQH ProView, One Healthport/Medversant, or Cigna's e-onboarding tool. Populate every section, explain any work history gaps, upload current documents, and confirm in writing which source Cigna will actually use for this application.
  3. Determine medical or behavioral routingMedical practitioners go through Cigna; behavioral health practitioners go through Evernorth. Confirm before submitting anything.
  4. Submit the participation requestApply through CignaforHCP.com with practice details, service locations, specialties and the products sought.
  5. Complete credentialing verificationCigna performs primary source verification and presents the file to its credentialing committee.
  6. Review and execute the contractConfirm fee schedule, products and networks included, and the effective date, then execute.
  7. Confirm identifiers, directory and effective dateRecord Cigna provider identifiers, verify the directory listing, and hold claims until the effective date.
  8. Diarise recredentialingTrack the recredentialing cycle centrally so participation is never suspended for a missed deadline.

Enrollment timeline and effective dates

Cigna's published expectation for a complete application is commonly framed around 45–60 days, but that figure assumes the eligibility call already happened, the documentation source is fully populated on the first pass, and nothing triggers a development request mid-review. In practice, the applications that blow past that window are almost always ones where the practice skipped straight to the documentation step, or where the wrong intake source was used and nobody discovered it until status was chased weeks in. A committee that requests additional information — on a work history gap, a malpractice history item, or a document that expired between preparation and submission — resets the clock on that specific piece rather than the whole file, but it still pushes the overall timeline out by however long the practice takes to respond, which is often longer than the request itself warranted simply because nobody was watching for it.

The effective/participation date itself is set once the contract is executed, not on the date the application was first submitted, so a slow contracting step at the end can add as much delay as a slow verification step in the middle. A practice that treats "credentialing approved" as the finish line and stops tracking the file loses weeks it never needed to lose, because the contract review and signature step is administrative rather than clinical and can sit on a desk exactly as long as nobody is asking about it. Full detail on what actually extends the 45–60 day window, how the effective date is determined, and how to check status through PSSCentral@Cigna.com without the status check itself adding delay, is in our enrollment timeline and effective dates guide.

Delegated credentialing for large groups

A group large enough to run its own NCQA-compliant credentialing program can apply for delegated credentialing with Cigna, under which the group verifies its own practitioners against Cigna's standards internally, and Cigna audits a sample of the resulting files on a recurring schedule rather than running primary source verification on every individual practitioner submitted. This meaningfully shortens the time to add a new provider to an already-delegated group, because the bottleneck moves from Cigna's committee queue to the group's own credentialing office, which can typically turn a file faster once it already has the infrastructure Cigna's delegation agreement requires.

  • 1NCQA-compliant program. A documented, audited internal credentialing process meeting NCQA credentialing standards, not an informal HR checklist.
  • 2Sufficient volume. Delegation exists to remove committee-level review from individual files, which only pays off at meaningful practitioner counts.
  • 3Periodic file audit. Cigna reviews a sample of the group's completed files on a recurring cycle and can suspend delegation if the sample fails.

It is a formal arrangement with its own application, its own compliance obligations, and real audit exposure if the group's internal process drifts from NCQA standards — not a shortcut a practice submitting one or two providers at a time should try to use standard individual credentialing to approximate. A small practice attempting to shortcut the standard process by informally mimicking delegated language on an application only slows things down, because Cigna still routes it through full committee review regardless of what the cover letter claims. Full detail on how delegation works, what the periodic file audit actually checks, and why small practices should stick to standard credentialing, is in our delegated credentialing guide.

Common application denials and how to fix them

Some of these show up as a formal rejection with a stated reason; more of them show up as a file that simply stops moving, which is why checking status proactively rather than waiting for correspondence matters more with Cigna than with a payer that always sends a rejection letter.

Most of these are correctable without a formal appeal — a corrected resubmission through the same channel is usually faster than disputing the outcome, and Cigna, like most commercial payers, would rather receive a clean corrected file than adjudicate a dispute over a technical rejection. Where a file has genuinely stalled with no explanation, or a network-closed response looks wrong given the practice's location or subspecialty, escalation runs through the credentialing option at 1-800-882-4462 or a direct status request to PSSCentral@Cigna.com with the provider's name and TIN ready before the call or email goes out, since that's the first thing any representative will ask for. The full escalation path, what a network-access reconsideration letter should say, and how long to wait before escalating a stalled file, are in our denial reasons and appeals guide.

Pro tip

Confirm whether each practitioner belongs to Cigna or Evernorth, and confirm the eligibility call actually happened, before you submit anything else. Behavioral applications sent to the medical network typically produce silence rather than a rejection, and documentation built before the eligibility call is sometimes built against a closed network. A five-minute check at the start prevents the two most common sources of delay with this payer — and it costs nothing to run that check even when you're fairly confident the answer is obvious, because the cost of being wrong is measured in months, not minutes.

Recredentialing cycle

Cigna recredentials participating practitioners on a cycle commonly framed around every three years, consistent with NCQA standards, and the process is triggered by a re-attestation request in whichever documentation source was used originally — CAQH, One Healthport/Medversant, or e-onboarding. Because the trigger arrives through the same channel as the original application, a practice that switched documentation sources between initial credentialing and recredentialing, or that let the original profile lapse once the provider was approved, can miss the notice entirely, sometimes for months, because nobody in the practice is checking a system nobody remembers using the first time around.

A lapsed recredentialing cycle can suspend network participation, and claims submitted during a suspension process as out-of-network rather than simply holding until the file is current again — which means the financial consequence of a missed recredentialing deadline looks identical to the financial consequence of never having credentialed the provider at all. Reinstatement afterward is not automatic; it typically requires completing the overdue re-attestation and, depending on how long the lapse ran, may involve a fresh review rather than simply picking up where the file left off. Full detail on the exact cadence, what re-attestation actually requires, and what a lapse does to claims already in the pipeline, is in our recredentialing cycle guide.

Do and don't

Do
  • Complete the pre-application eligibility call before gathering any documentation.
  • Route behavioral health practitioners through Evernorth from the outset.
  • Confirm in writing which of the three documentation sources Cigna is actually using.
  • Confirm both credentialing approval and contract execution in writing.
  • Verify the directory listing after approval, and track recredentialing centrally with a named owner.
  • Keep the tracking or web reference number from every submission in a shared log the whole team can see.
Don't
  • Don't skip the eligibility call and go straight to paperwork.
  • Don't submit behavioral providers through the medical pathway.
  • Don't keep CAQH current while assuming that's the source Cigna is reading from.
  • Don't treat credentialing approval as network participation.
  • Don't let recredentialing lapse, and don't try to approximate delegated credentialing without the formal arrangement.
  • Don't wait for Cigna to ask about a documentation gap you already know is there.

Frequently asked questions

Why has our Cigna application gone quiet?

The most common cause is a behavioral health practitioner submitted through the medical pathway. Those applications tend to stall rather than generate a formal rejection, so nothing arrives to tell you the file is not progressing. The second most common cause is a documentation source (CAQH, One Healthport/Medversant, or e-onboarding) that is unattested or not authorised for Cigna, which halts verification before any human review. Check both, and check whether the pre-application eligibility call ever actually happened, before chasing status.

What is Evernorth and when do we use it?

Evernorth is Cigna's health services organisation, and it administers behavioral health credentialing, contracting and networks. Therapists, psychologists, psychiatrists and substance use treatment providers generally credential through Evernorth rather than the Cigna medical network. Practices with both medical and behavioral clinicians need to run both processes in parallel, with separate contracts and separate effective dates.

Does credentialing approval mean we are in network?

No. Credentialing verifies the practitioner's qualifications; the executed contract establishes network participation, the products included and the fee schedule. Both are required. Seeing Cigna patients on the strength of credentialing approval alone results in out-of-network processing, which creates a revenue shortfall and a patient balance issue that is awkward to unwind afterwards.

How do we handle a closed network?

Approach it as a commercial matter rather than a credentialing one. Build a reconsideration around access: an underserved area, a subspecialty the network lacks, extended hours, language capability or a referral pattern currently leaving the network. Single-case agreements can cover urgent individual cases in the interim. Networks reopen periodically, so keep the request live and revisit rather than treating a closure as final.

Can you run Cigna and Evernorth applications together?

Yes. We route each practitioner to the correct organisation at the outset, maintain a single accurate documentation profile that both can draw from, track the two processes separately with their own committee timelines and effective dates, and confirm contract execution before advising that any provider is billable. Recredentialing for both is tracked on the same central calendar.

What is Cigna's pre-application eligibility call?

It is a phone screen Cigna runs before any documentation is pulled, confirming whether the practitioner's specialty and service area currently have an open network need. It exists because Cigna, like most large commercial payers, closes specific specialties and regions to new participation from time to time, and running the call first avoids building a complete file against a network that will not accept it. Skipping straight to CAQH or e-onboarding without confirming eligibility first is the single most avoidable delay in the whole process.

Can a large group credential its own providers under Cigna?

Groups large enough to run an NCQA-compliant credentialing program of their own can apply for delegated credentialing, under which the group verifies its own practitioners against Cigna's standards and Cigna audits the resulting files periodically rather than running primary source verification on every individual. It is a formal arrangement with its own application and ongoing audit obligations, and it is not a shortcut available to a small practice submitting one or two providers at a time.

We make the eligibility call, prepare and submit through the right source, and tell you the week each provider becomes billable.
