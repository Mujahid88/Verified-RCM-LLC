ICD-10 codes for care management: which ones find your patients, and which ones get rejected.

Diagnosis codes do two jobs in a care management program. They help you find the patients who may qualify, and they have to be on the claim in the right order and the right form. They do not prove eligibility. Eligibility comes from the chart: the risk, the complexity and the treatment plan. This page lists valid codes for each service and the incomplete ones that payers reject.

Prepared by Verified RCM · Part of our care management guide · All codes validated against the FY2027 ICD-10-CM code set on November 3, 2026

Key takeaways

  • A code alone never proves eligibility. The chart has to show the condition’s duration, the risk and, for PCM, the complexity.
  • List the qualifying diagnosis first. For RTM, the musculoskeletal code goes first as a best practice.
  • Use the most specific code. Category headers such as M54.5, M51.36 and G90.5 are rejected because they need further characters.
  • The code must be valid on the date of service. The FY2027 set covers October 1, 2026 to September 30, 2027.
  • We found no payer that publishes a required diagnosis list for these services, so the lists below are our patient-finding aids, not payer rules.

PCM: one serious condition, listed first

PCM needs one serious, high-risk condition expected to last at least three months. Document why it is high risk and complex to manage; the diagnosis code is only the starting point.

CCM: two or more chronic conditions

Pair a pain condition from the PCM table or the RTM table with at least one of these, and make sure the chart shows each is expected to last at least 12 months and places the patient at significant risk.

RTM: a musculoskeletal code first

The musculoskeletal device codes 98977 and 98985 need data that relates to a musculoskeletal condition and treatment plan. List the musculoskeletal diagnosis first as a best practice, so the link between the data and the condition is obvious on the claim.

Chronic pain management (G3002)

G3002 is for pain lasting more than three months. The diagnosis is typically G89.29 or G89.4 plus the underlying condition from the PCM or RTM tables.

Codes that will be rejected

Incomplete codes. The following are category headers, not billable codes, and fail HIPAA validation: M54.5, M51.36, M51.37, G89.2, G90.5, G90.51, G90.52, E66.8 and E66.81. Add the characters that make them complete, for example M54.51, M51.362, G89.29, G90.511 and E66.811.

A code that was valid last year can be deleted or split, and a code added in October is not valid for services before its effective date. The FY2027 set covers October 1, 2026 to September 30, 2027. Check your claim scrubber’s code tables after each annual update; our claims scrubbing guide covers the edit categories that catch them.

Frequently asked questions

Does the diagnosis code qualify the patient for CCM or PCM?

No. The code helps you find patients, but eligibility comes from the chart: for CCM, two or more conditions expected to last at least 12 months with significant risk; for PCM, one condition expected to last at least three months that is high risk and complex to manage.

Why is M54.5 rejected?

M54.5 is a category header. It was expanded to M54.50, M54.51 and M54.59, and the header alone is not valid for HIPAA transactions. Use the most specific code the documentation supports.

Which diagnosis do we list first for RTM?

The musculoskeletal diagnosis the monitoring supports, as a best practice. Chronic pain syndrome and similar codes are not musculoskeletal codes and are secondary for RTM.

Do payers publish required diagnosis lists?

We found none for these services among the payers we reviewed. A payer or a contract may still apply its own edits, which the benefits check should ask about.

What if the patient has two pain conditions?

For PCM, choose the one serious condition the program manages and build the care plan around it. For CCM, list each qualifying condition and make sure the care plan covers all of them.

Confirm before you rely on this. Every code on this page was validated against the FY2027 ICD-10-CM code set, in effect October 1, 2026 to September 30, 2027. A code has to be valid on the date of service, and a code alone never proves eligibility. Diagnosis lists are for finding likely patients, not for deciding coverage.
