Endocrinology NCCI edits and MUE limits: bundling rules explained.

Endocrinology's bundling denials cluster around four spots: a thyroid FNA billed with a redundant guidance code, a same-day E/M that lost its modifier 25 support, a chronic care management claim that double-counted time already billed elsewhere, and a diabetes education session that collided with the same day's office visit. Only some of these are genuine NCCI Procedure-to-Procedure edits with a modifier indicator attached, others are code-design, global-package, or coverage-policy rules that look like bundling but run on entirely different logic. This guide separates the two and gives you the modifier-indicator and MAI framework to tell, before staff time goes into an appeal that was never going to succeed.

Reviewed by Phares A., MD · Physiotherapist, CPC (AAPC) · Part of our NCCI edits and bundling guide for endocrinology

Key takeaways

  • 76942 with 10005 or 10006 isn't a bypassable edit, it's a coding-selection error. Ultrasound guidance for a thyroid FNA has been part of those codes' own descriptors since CPT's 2019 restructuring, so no modifier makes the pair separately payable; the fix is dropping the guidance line, not appealing.
  • A same-day E/M with a thyroid biopsy runs on the global surgery package, not a specific PTP pair. Modifier 25 is defensible only when the note shows work beyond the routine pre-biopsy assessment already bundled into the procedure code.
  • CCM (99490) and a same-month E/M aren't mutually exclusive, double-counted time is the actual rule. Minutes billed under a face-to-face E/M can't also count toward the 20-minute CCM threshold, and non-complex and complex CCM can't both be reported the same month.
  • DSMT (G0108/G0109) same-day billing turns on which NPI bills the E/M, not on a Column 1/Column 2 pair. Same NPI, same day, usually means one payable service unless the E/M documents work distinct from the education session.

The two indicators that decide every bundling fight

Two CMS-published values control whether an endocrinology code pair or a unit-capped code is billable at all, and neither is something you infer from experience, both are specific, quarterly-updated values attached to the exact codes on your claim.

The NCCI Procedure-to-Procedure modifier indicator, attached to a Column 1/Column 2 code pair:

  • 0Never bypassable. The second code in the pair is not separately payable under any circumstances, no modifier, however well the record documents distinctness, changes that.
  • 1Bypassable with documentation. An NCCI-associated modifier (59 or the specific X-modifier) can override the edit, but only when the chart genuinely shows the second service was separate, different lesion, different session, different anatomic site.
  • 9Edit deleted. The pair no longer applies; don't build a scrubber rule around a stale indicator value.

The MUE Adjudication Indicator (MAI), attached to a per-code, per-day unit cap:

  • 1Claim-line edit. Units above the cap deny that line, but a genuinely repeated service can often be split across lines with the correct modifier.
  • 2Absolute, date-of-service edit. CMS treats exceeding it as clinically implausible. There's no appeal path, confirm the MAI before staff spend time on one.
  • 3Appealable, date-of-service edit. A real path exists with documentation the excess units reflect genuinely distinct, medically necessary sessions.

⚠️ This build could not query CMS's primary NCCI Procedure-to-Procedure edit file or MUE tables directly to confirm the current-quarter indicator or MAI value for any individual endocrinology code pair discussed below. The structural rules in the next four sections hold independent of those values, they follow from each code's own descriptor, from CPT panel and global-period rules, or from Medicare's DSMT coverage policy, not from a Column 1/Column 2 lookup. Where a specific indicator or MAI value would matter to a scrubber rule, it's flagged; verify the current value in the CMS NCCI PTP Edits Lookup Tool before relying on it.

Thyroid FNA and ultrasound guidance: bundled by code design, not by PTP edit

This is the single most common bundling question in endocrinology billing, and getting the distinction right matters more than the codes themselves: there's a real difference between a service that's already bundled into a code's own definition and a service that's bundled by an NCCI edit that could, in the right circumstances, be unbundled with a modifier and documentation. Thyroid FNA imaging guidance is the first kind. It was never a modifier-overridable edit to begin with.

CPT restructured the fine needle aspiration family in 2019, replacing the old single guidance-agnostic code (10022) and its frequent 76942 add-on with a set of codes that build the imaging modality directly into the descriptor:

A thyroid nodule aspirated under real-time ultrasound is 10005 for the first lesion and 10006 for each additional lesion biopsied the same session, and both codes already include the guidance work. Billing 76942 (ultrasonic guidance for needle placement, imaging supervision and interpretation) alongside either one doesn't unbundle a Column 1/Column 2 pair; it double-bills a component the base code already paid for. There's no modifier that fixes this, because there's nothing to override, the correction is removing the 76942 line, not appending 59 or an X-modifier and hoping the edit clears. Contrast that with a genuine PTP pair elsewhere on the claim: there, indicator 1 means documentation of true distinctness earns separate payment. Here, no documentation changes the outcome, because the guidance was never a separate service to begin with.

Two documentation points that decide which row of the table even applies. First, real-time ultrasound use has to be explicitly stated in the procedure note, "ultrasound-guided FNA" or equivalent language describing simultaneous imaging during needle placement. A note that only says a prior diagnostic ultrasound identified the nodule, without documenting guidance during the aspiration itself, supports 10021 (palpation-guided), not 10005, regardless of what equipment was in the room. Second, multiple thyroid nodules aspirated the same session are reported as one unit of the first-lesion code plus one unit of the additional-lesion code per nodule beyond the first, not as repeated first-lesion codes, which is the pattern that trips MUE logic on this family. ⚠️ The current MAI value for 10006 and the other additional-lesion codes wasn't independently confirmed against CMS's live MUE table during this build; confirm it before setting a hard unit-cap rule in your scrubber.

Same-day E/M with a thyroid biopsy: what actually earns modifier 25

Like the joint-injection-and-E/M question in other specialties, this one is frequently filed under NCCI when it isn't governed by the PTP file at all. FNA biopsy codes carry a minor-procedure global period, and it's the global surgery package rules in the NCCI Policy Manual's general policy chapter, not a specific Column 1/Column 2 value you can look up for 99213-99215 against 10005, that require a same-day E/M to be significant and separately identifiable before modifier 25 makes it payable.

The routine pre-procedure work is already inside the biopsy code's own valuation: confirming the correct nodule, obtaining and documenting informed consent, positioning the patient, and the brief exam performed specifically to plan the aspiration. An E/M billed for exactly that work, with no other content, doesn't support modifier 25 no matter how it's coded. What does support it: the same visit also addressing a new symptom unrelated to the nodule, adjusting levothyroxine or antithyroid medication dosing based on current labs, managing a comorbid endocrine condition (diabetes, adrenal insufficiency), or working up findings on the thyroid ultrasound beyond the nodule being biopsied that day. The distinguishing test an auditor applies is whether the E/M note would stand on its own as a complete, medically necessary visit if the biopsy weren't happening at all, if it would, 25 is defensible; if the entire note is scaffolding around the decision to biopsy, it isn't.

Because this rule lives in the global-period policy rather than a PTP pair, a scrubber tuned only to catch Column 1/Column 2 edits won't flag a mismatch here, and an appeal for a denied same-day E/M has to lead with the note's actual content, not with an indicator value, since there isn't one attached to this particular combination.

CCM (99490) and same-month E/M: the double-counting rule, not a bundling edit

Chronic care management is where endocrinology practices most often assume a bundling restriction exists that doesn't. 99490 (non-complex CCM, at least 20 minutes of clinical staff time under general supervision, per calendar month) is not blocked from being billed in the same month as an office E/M visit for the same patient, Medicare's own CCM guidance permits both. What's actually restricted is time double-counting and same-day E/M stacking, not the CCM-plus-E/M combination itself.

  • 1Time can't be counted twice. Minutes spent during a face-to-face E/M encounter, reviewing labs with the patient, adjusting insulin or GLP-1 dosing during the visit, can't also be logged toward the 20-minute CCM threshold for that month. CCM time has to be genuinely separate, typically non-face-to-face care coordination work performed outside the visit.
  • 2Only one E/M per day, absent modifier 25. This isn't specific to CCM, it's the general same-day E/M rule, but it matters here because CCM's initiating visit and any later E/M on the same date have to clear the same modifier 25 bar as any other same-day E/M pair.
  • 3Non-complex and complex CCM don't stack in the same month. A patient can't be billed 99490/99439 and 99487/99489 for the same calendar month; the complexity level is chosen once per month based on the clinical staff time and care-plan complexity actually furnished.
  • 4CCM and TCM can coexist, but not overlap. Transitional care management (99495/99496) covers the 30 days following a discharge; CCM time for that patient can't begin until the TCM service period has ended, even though both can appear on the same patient's record within the same broader month.

The other condition that's easy to miss on audit: the E/M, annual wellness visit, or initial preventive physical exam has to have actually included a documented discussion of chronic care management, the patient's consent, the care-management services being offered, cost-sharing, before it can serve as CCM's required initiating visit. A qualifying E/M that never raised CCM doesn't retroactively become the initiating encounter just because CCM starts the following month. None of this is an NCCI Procedure-to-Procedure edit; it's Medicare's own CCM billing policy, and it belongs in your care-management workflow documentation, not in a PTP-only claims scrubber.

DSMT (G0108/G0109) same day as an E/M visit

Diabetes self-management training runs on a coverage and same-NPI billing rule rather than a Column 1/Column 2 edit, and the outcome turns on who bills the E/M relative to who bills the education session.

  • 1Same billing NPI, same day. When the physician or practice that bills the office E/M is the same billing entity furnishing the DSMT that day, Medicare typically treats the visit and the education session as one bundled encounter unless the E/M documents medically necessary work distinct from, and beyond, the diabetes education content itself.
  • 2Different billing NPI, same day. A common structure when DSMT is furnished through a separately accredited diabetes education program: if that program bills under its own NPI, separate from the physician's E/M, both services can be separately payable provided the E/M independently meets medical necessity.
  • 3Unit caps apply regardless of billing structure. G0108 (individual DSMT, per 30 minutes) is capped at a same-day maximum, and G0109 (group DSMT, per 30 minutes) has its own, higher same-day cap, confirm both against current MAC guidance before scheduling back-to-back individual sessions on one date of service.

This is a coverage-policy and billing-entity question, not an NCCI pair, which is exactly why it won't show up in a PTP-only lookup tool the way the thyroid FNA guidance issue would. ⚠️ The specific same-day unit caps for G0108 and G0109 and the exact medical-necessity documentation language your MAC expects weren't independently confirmed against a jurisdiction-specific local coverage article during this build; verify both against your MAC's current DSMT billing guidance before relying on them in a workflow rule, since diabetes education coverage details can vary by contractor.

Do
  • Check whether a "bundling" denial is actually a coding-selection error (10005+76942, individual panel components) before assuming it's a Column 1/Column 2 edit.
  • Confirm the modifier indicator before writing any override-modifier appeal, and the MAI before writing any unit-cap appeal.
  • Document CCM time as genuinely separate from any same-month face-to-face E/M work.
  • Confirm which billing NPI is submitting the E/M versus the DSMT session before assuming both are separately payable.
Don't
  • Don't append 59 or an X-modifier to 76942 alongside 10005 or 10006 hoping it clears the edit, the fix is dropping the line entirely.
  • Don't bill an E/M with modifier 25 alongside a thyroid biopsy when the note only documents the pre-procedure assessment.
  • Don't assume CCM and a same-month E/M conflict, the actual restriction is on double-counted time and same-month CCM complexity stacking.
  • Don't write a bundling appeal before confirming whether the edit is even the bypassable kind.
Pro tip

Before assigning an endocrinology bundling denial to your appeals queue, ask whether it's a genuine Column 1/Column 2 edit at all. If it's 10005 plus 76942, a same-day E/M with only pre-biopsy documentation, or a DSMT same-NPI same-day conflict, the fix is a code correction, better documentation, or a billing-structure change, not an appeal letter citing an indicator value. Save the indicator-and-MAI lookup for cases that are actually PTP pairs, and confirm the current value every quarter before it drives a scrubber rule.

Frequently asked questions

Is billing 76942 alongside 10005 for a thyroid FNA an NCCI edit we can bypass with a modifier?

No, and this is the single most common bundling mistake in endocrinology billing. 10005 (fine needle aspiration biopsy, first lesion, including ultrasound guidance) already has real-time ultrasound guidance built into its own code descriptor, it replaced the old 10022-plus-76942 combination when CPT restructured the FNA family in 2019. Billing 76942 on top of 10005 or 10006 isn't a Column 1/Column 2 pair with a modifier indicator to look up; it's double-billing a component of a single code. There's no override modifier because there's nothing to override, the fix is dropping the separate guidance line, not appending 59 or an X-modifier to it.

Can we bill an E/M visit the same day as a thyroid FNA biopsy?

Yes, with modifier 25 on the E/M code, but only when the note supports it. FNA codes carry a minor-procedure global period, so the global surgery package rules, not a specific NCCI Procedure-to-Procedure pair, require the E/M to be a significant, separately identifiable service beyond the routine pre-procedure assessment (confirming the nodule, obtaining consent, prepping the site) that's already bundled into the biopsy code. A visit that also works up a new symptom, manages thyroid hormone dosing, or evaluates an unrelated endocrine complaint supports 25; a visit that's solely "here to biopsy the nodule" does not.

Can CCM (99490) be billed the same month as an office E/M visit?

Yes. Medicare doesn't prohibit billing an E/M visit and 99490 in the same calendar month, the restriction is on double-counting time, not on billing both services. Any minutes spent during a face-to-face E/M visit can't also be counted toward the 20-minute CCM time threshold for that month, and only one E/M can be billed per day unless modifier 25 supports two. Separately, non-complex CCM (99490/99439) and complex CCM (99487/99489) can't both be reported for the same patient in the same calendar month, and CCM time can't begin until any overlapping transitional care management period has ended.

Is DSMT (G0108/G0109) separately payable from an E/M visit on the same day?

It depends on who bills it and what the E/M documents. When the office E/M and the DSMT session are billed under the same billing NPI the same day, Medicare typically does not pay both unless the E/M documents medically necessary, separately identifiable work beyond the diabetes education itself. When the DSMT is furnished and billed by a distinct accredited program or a different billing NPI, common when a practice contracts out its diabetes education, both can be separately payable. Either way, confirm the current 3-hour individual (G0108) and 6-hour group (G0109) same-day unit caps before submitting either line.
