Dermatology billing and coding: the complete 2026 guide.

Dermatology bills more distinct procedure codes per patient visit than almost any other specialty — a single lesion check can generate an E/M, a biopsy, and a destruction code on the same claim, each governed by its own bundling logic. Every competitor guide we reviewed tells you to "check your MAC's LCD" for Mohs coverage without naming a single one; this pillar names all seven. It also pairs the 2026 technique-specificity documentation mandate to the exact denial it prevents, and gives you a full excision-and-repair code table instead of a prose size range. Here's the complete 2026 guide: what changed, every core procedure family, the MAC-specific coverage citations nobody else publishes, and the denial-to-appeal pairing that actually gets claims paid.

Reviewed by Phares A., MD · Physiotherapist, CPC (AAPC) · Updated August 2026

Key takeaways

  • Seven MACs publish seven separate Mohs LCD articles — Novitas A53883, Palmetto GBA A56732, WPS A57477, CGS A56836, Noridian A56514, and First Coast A57767 — and no competitor guide we reviewed names a single one of them.
  • The 2026 documentation mandate is the single biggest operational change. Biopsy and destruction codes now require the specific technique or method named in the note, not just "biopsy performed" or "lesion destroyed."
  • Biopsy-into-excision bundling on the same lesion is a CPT correct-coding rule, not just an NCCI edit — and the edit's modifier indicator, not documentation alone, decides whether 59 or an X-modifier can ever override it.
  • Medicare's teledermatology coverage is narrower than most guides imply. Store-and-forward (photo-only) consults are covered nationally only in the Alaska/Hawaii demonstration — everywhere else, only a real-time visit bills as telehealth.

Dermatology billing at a glance

Dermatology's revenue cycle runs on four code families that stack on top of each other in a single visit — biopsy, excision, destruction, and Mohs — each with its own size, site, and technique rules, plus an E/M layer that has to be justified as separately identifiable every time it shares a claim with a procedure. Add in ICD-10 specificity that decides whether a payer treats a lesion removal as medically necessary or cosmetic, and you have a specialty where the coding decision, not just the clinical one, determines whether the claim gets paid at all. Here's the shape of it before the detail.

What changed in dermatology coding for 2026

2026 didn't restructure dermatology's code set the way it did cardiology's — the biopsy, excision, destruction, and Mohs families are all the same codes practices have used for years. What changed is what a chart has to say to support those codes, and that documentation shift is the change most practices are underprepared for, because it doesn't show up as a denial on code validity the way a deleted code does. It shows up months later, on a records request or a payer audit, when the note doesn't support what was billed.

The practical fallout of the documentation mandate: a coder can still select the correct code from a thin note, because the code itself didn't change and the clinical picture is usually obvious to the person who saw the patient. What the thin note can't do is survive a payer audit or a records request, where the reviewer isn't looking at the patient — they're looking at whether the words on the page support the code on the claim. Build the technique and method language into your templates now, not after the first records request comes back.

This isn't the first time dermatology's biopsy family has changed at the documentation level rather than the code level. The 2019 CPT revision that created the current tangential/punch/incisional structure was itself a response to the same underlying problem — the prior code set billed biopsies almost entirely by count, with far less attention to which technique was actually performed, and payers had no reliable way to confirm the technique matched the code. 2026 extends that same logic downstream to destruction: a code family that's historically been billed almost entirely by lesion count and type now needs the method documented with the same rigor biopsy technique has needed since 2019. Practices that already tightened their biopsy templates in response to the 2019 change have a head start; practices that never did are now exposed on two code families at once.

The compliance exposure runs in a specific direction: none of this changes what gets paid at the point of submission, because claims scrubbers don't reject a claim for thin documentation — they reject for invalid codes, missing modifiers, or failed edits. A biopsy or destruction claim with a documentation gap clears the clearinghouse and gets paid normally. The risk surfaces later, in a payer audit, a RAC review, or a records request tied to an unrelated claim, when the reviewer pulls the chart and the note doesn't support the code. That delay is exactly what makes this change easy to underestimate operationally — the first sign of a problem isn't a denial, it's a takeback request months after the fact.

⚠️ The exact 2026 flat rate for skin substitutes could not be confirmed to a single dollar figure during this build — secondary sources reported figures between $127.14 and $127.28 per cm² across three new APCs (6000, 6001, 6002) sorted by FDA regulatory category. Confirm the current rate directly against the CMS OPPS/ASC final rule or your MAC before billing against it; this affects wound-care and chronic ulcer applications far more than routine lesion work, but any dermatology practice applying cellular tissue products should verify the number before billing.

E/M coding in dermatology: full-body exams and modifier 25

New-patient (99202–99205) and established-patient (99212–99215) office visits are leveled on either total time or medical decision making, whichever the note fully supports — not a blend of both. A full-body skin exam for a patient with a history of melanoma, a chronic condition follow-up for psoriasis or atopic dermatitis, or a new-patient lesion evaluation all level the same way as any other E/M: 99214 requires 30–39 minutes of total time or moderate-complexity MDM, 99215 requires 40–54 minutes or high-complexity MDM. The common underbilling pattern in dermatology is a full-body exam with multiple concerning lesions, a biopsy decision, and a treatment plan for a chronic condition — genuinely 99215-level complexity — documented in a note that only supports 99214 because the number of problems addressed and the data reviewed weren't captured explicitly.

New-patient visits run a materially higher time threshold at every level than the equivalent established-patient code, because the work of building a full history and problem list from nothing is baked into the code itself — a new-patient full-body skin exam with a substantial history and multiple lesion evaluations routinely supports 99204 or 99205 even when the individual findings, taken one at a time, would only support a mid-level established code.

Modifier 25 is where same-day E/M and procedure billing gets decided, and it's dermatology's highest-volume modifier by claim count. It applies when a significant, separately identifiable E/M service is performed the same day as a minor procedure — a lesion check that turns into "let's biopsy this one and destroy these three actinic keratoses" is the textbook dermatology scenario. The E/M has to stand on its own: a distinct history, exam, and medical decision making beyond what's inherently part of performing the procedure. Billing 25 on every visit that includes any procedure, regardless of whether the E/M work was actually separate from the pre-procedure assessment, is one of the most consistently audited patterns in the specialty.

Modifier 25 applies
  • New complaint or new lesion evaluated in the same visit as an unrelated scheduled procedure.
  • A full-body skin exam that identifies multiple lesions, several of which are biopsied or destroyed the same day.
  • Chronic condition management (psoriasis flare, atopic dermatitis treatment adjustment) addressed alongside a scheduled destruction visit.
Procedure-only, no 25

  • A pre-procedure assessment that's inherent to the procedure itself — checking the lesion, confirming the plan, obtaining consent.
  • A post-biopsy follow-up scheduled only to discuss pathology results and plan the excision.

Chronic condition management carries its own leveling logic worth calling out separately, because it's where dermatology E/M most resembles primary care rather than a procedural visit. A psoriasis or atopic dermatitis follow-up that adjusts a topical regimen, reviews a biologic's effectiveness, or manages a flare typically supports 99213–99214 on MDM alone — one chronic illness with exacerbation, prescription drug management — without any procedure attached at all. Where these visits get underbilled is biologic monitoring: a visit that reviews lab work, assesses infection risk, and manages a high-risk medication is data-and-risk-heavy MDM even when the exam itself is brief, and a note that only describes the skin exam misses the MDM complexity that's actually driving the visit.

Personal or family history of skin cancer changes the medical-necessity picture for a full-body surveillance exam, and it belongs in the diagnosis coding for the E/M, not just the clinical note. A personal history of melanoma or non-melanoma skin cancer, or a documented family history, supports the medical necessity of a recurring full-body exam in a way that a routine well-visit code doesn't — carry that history code on the claim consistently, not only on the visit immediately following treatment.

Prolonged services add-on code 99417 applies when a visit genuinely runs past the top time threshold of the highest-level E/M code billed — a complex new-patient full-body exam with extensive counseling that runs 20 minutes beyond the 99205 time threshold, for example, supports 99205 plus a unit of 99417 for each additional 15-minute increment. It's billed on top of a time-based E/M level, never in place of one, and only once the full threshold for the base code is met and exceeded by a genuine additional increment, not for a visit that merely runs a few minutes long.

Dermatology practices lean heavily on physician assistants and nurse practitioners for high-volume visit types — lesion checks, biologic follow-ups, routine destruction visits — and shared or split visit billing rules govern how those encounters get billed when both a physician and a non-physician practitioner are involved in the same visit. Under current Medicare rules, the billing practitioner on a shared visit is whichever clinician performs the substantive portion of the visit, determined by either time or the MDM they personally performed — not automatically defaulted to the supervising physician regardless of who actually did the bulk of the work. Where a PA or NP sees the patient independently for a straightforward lesion check with no physician involvement in the visit itself, that's billed under the non-physician practitioner's own NPI, not incident-to the physician, unless the specific incident-to requirements (physician on-site, established plan of care, no new problem) are actually met.

Skin biopsy coding: 11102–11107 and the 2026 documentation rule

Biopsy coding in dermatology has run on technique, not just anatomy, since the base codes were revised in 2019 — and the 2026 documentation mandate is the next layer on top of that same structure, not a new code set.

Skin biopsy codes by technique. One base code per session, regardless of how many techniques are used.
TechniqueFirst lesionEach additional lesion
Tangential (shave, scoop, saucerization, curette)11102+11103
Punch (circular tool, cylindrical core sample)11104+11105
Incisional (partial-thickness blade incision, deeper than punch, short of full excision)11106+11107

The rule that trips up coders unfamiliar with the 2019 revision: only one base code (11102, 11104, or 11106) is reported per patient per session, even when multiple techniques were used on different lesions the same visit. Report the base code matching the technique on the first lesion documented, then use the add-on code matching each additional lesion's own technique — a punch biopsy followed by two tangential biopsies bills as 11104 plus two units of +11103, not 11104 plus 11102.

Documentation now has to carry four elements per lesion to support the code on audit: the specific technique used, the anatomic site, the lesion size, and clinical justification when the technique choice itself needs explaining — an incisional biopsy on a lesion a punch could reasonably have sampled draws exactly the kind of audit question a documented rationale prevents. "Biopsy of right forearm lesion" no longer carries the claim; "3mm punch biopsy of a 6mm pigmented lesion, right forearm" does.

Worked example: a patient presents with three lesions of concern. The physician performs a shave biopsy of a 5mm lesion on the back (tangential), a punch biopsy of an 8mm lesion on the scalp (punch), and a second shave biopsy of a 4mm lesion on the chest (tangential). Because the encounter includes two techniques, the base code is selected from the first lesion documented — if the back lesion is documented first, that's 11102 as the base, with the scalp punch reported as +11105 (punch add-on) and the chest shave reported as +11103 (tangential add-on). The base code is billed once regardless of which lesion happens to be listed first in the note, but consistency in how the note orders lesions matters for audit clarity — document lesions in the order performed, not reshuffled after the fact to make the coding cleaner.

Where this family denies most often: billing multiple units of the same base code (e.g., two units of 11104) instead of one unit of the base code plus a unit of the matching add-on for each additional lesion, and biopsying a lesion that's excised in the same session without documenting them as anatomically distinct. Payers that request records on a high-volume biopsy claim are increasingly looking specifically for the technique word — tangential, punch, or incisional — appearing in the procedure note itself, not inferred from the CPT code billed.

Tangential biopsy is also the point where dermatology coding most often gets confused with a related but distinct service: shave removal of a lesion for cosmetic or benign-lesion-management purposes, rather than for diagnostic sampling, isn't a biopsy at all — if the entire visible lesion is removed by shave technique with no remaining tissue and no diagnostic uncertainty driving the procedure, that's more accurately a benign excision or destruction depending on technique and intent, not 11102. The distinction turns on intent and completeness documented in the note: a biopsy samples tissue to establish or confirm a diagnosis, even when the technique happens to remove the entire visible lesion; a shave removal removes the lesion because it's already diagnosed or benign and the removal itself is the treatment. Document which one the visit actually was — the CPT family selected has to match the clinical intent, not just the technique used.

A technique that changes mid-procedure needs to be documented as what was actually done, not what was originally planned. A punch biopsy attempted on a lesion that turns out to require conversion to an incisional approach mid-procedure — because the initial sample was inadequate or the lesion's depth wasn't apparent until the procedure began — bills based on the technique that produced the diagnostic specimen, with the note explaining why the conversion happened. Billing the originally planned technique because that's what the order said, rather than what was actually performed, is a documentation-practice mismatch that surfaces exactly the kind of discrepancy a records request is designed to catch.

Lesion excision coding by size and margin: 11400–11646

Excision size is measured as the lesion's greatest diameter plus the narrowest margin required for complete excision, taken before the tissue is removed — not the size of the defect after excision, and not the size of the specimen once it's contracted in formalin. Get that measurement point wrong and the code selected won't match what the pathology report or the payer's own review implies, which is one of the most common excision-coding disputes on audit. Formalin fixation shrinks tissue by a meaningful margin, so a specimen that measures smaller on the pathology report than the pre-excision measurement in the operative note isn't a documentation error — it's an expected artifact of processing, and the operative note's measurement, taken with the patient still on the table, is the one that governs code selection.

For an elliptical excision, the margin is measured at the narrowest point around the lesion, not the longest axis of the ellipse itself — a common source of overstated size when a coder measures the full length of the surgical ellipse (which includes the tissue removed to allow a straight-line closure) rather than the lesion diameter plus the clinically necessary margin. Document both numbers separately in the operative note: lesion diameter, and margin taken, so the size bracket selected is traceable to the two components that actually define it.

Simple closure — a single-layer suture with no significant undermining — is bundled into every excision code above and is never separately billable. Once the closure requires layered suturing to reduce dead space and support the wound (intermediate repair) or extensive undermining, retention sutures, or reconstruction with a graft or flap (complex repair), those become separately billable on top of the excision:

  • 1Intermediate repair (12031–12057). Layered closure of one or more wound layers, coded by anatomic site group and total repair length in centimeters, summed across all wounds repaired at that complexity in the same anatomic grouping during the same session — not billed per individual excision.
  • 2Complex repair (13100–13153). Repair requiring more than layered closure — extensive undermining, scar revision, retention sutures, or debridement of complicated wounds — also summed by length and anatomic site group across the session.

The summing rule is where practices leave money on the table or overbill without realizing it: if a session includes three excisions on the trunk with intermediate repairs measuring 2cm, 3cm, and 2.5cm, that's one intermediate repair code selected by the 7.5cm total, not three separate repair codes. Worked example: a 1.8cm malignant lesion excised from the arm (excised diameter with margin) bills 11602 (1.1–2.0cm, trunk/arms/legs group), and if the resulting defect requires a layered closure measuring 4cm, that's billed separately as the appropriate intermediate repair code from the 12031–12037 range covering that length on that anatomic grouping — two line items, two separate size brackets, each measured against its own governing dimension (lesion-plus-margin for the excision, closure length for the repair).

Anatomic site grouping has to match between the excision and the repair code, or the repair code selected won't correspond to a real CPT category — the three excision site groups (trunk/arms/legs; scalp/neck/hands/feet/genitalia; face/ears/eyelids/nose/lips/mucous membrane) don't map one-to-one onto the repair code groupings, which split slightly differently by complexity tier. Confirm the repair code's own anatomic grouping independently rather than assuming it mirrors the excision code's group.

Excision and destruction aren't interchangeable for the same clinical picture, and the choice between them is a real coding decision, not a formality. Destruction removes tissue by ablation with no specimen suitable for margin assessment; excision removes tissue as an intact specimen that pathology can examine for clear margins. A lesion where margin status matters clinically — any suspected malignancy, or a benign lesion where the diagnosis itself is uncertain — should be excised, not destroyed, specifically so a pathology report exists to confirm what was actually treated. Choosing destruction for a lesion that should have been excised, often because it's the faster in-office option, is a clinical decision with billing consequences: there's no excision code to select later if the destroyed tissue turns out to have been something that needed margin confirmation, and no re-billing path recovers that.

Excision codes carry a 10-day global surgery period under Medicare's global surgery rules, which governs how a follow-up visit in that window gets billed. A suture removal or wound check within those 10 days is bundled into the excision's own payment and isn't separately billable on its own; an E/M for a new, unrelated problem during that same window is billable with modifier 24 attached, exactly as it would be for any other procedure's global period. Where the follow-up visit reveals a complication genuinely requiring a return to the operating room or procedure room, modifier 78 (unplanned return to the procedure room for a related complication during the global period) applies instead of 58, which is reserved for a planned, staged procedure rather than an unplanned complication.

Lesion destruction: premalignant, benign, and malignant

Destruction codes split into three families by lesion type, and each family counts lesions differently — a distinction that causes real billing errors when a coder applies one family's counting logic to another.

Notice the structural difference: premalignant destruction bills per-lesion all the way up (17000 plus a unit of +17003 for each of lesions 2 through 14, then a single 17004 replaces all of it at lesion 15), while benign destruction bills 17110 once regardless of count up to 14, with +17111 added only once the count crosses into 15 or more. Applying premalignant per-lesion logic to a benign destruction claim is a common source of overbilled units that a payer's own system catches immediately, because the MUE for 17110 is built around its "up to 14, one code" structure.

The 2026 method-specificity mandate applies across all three families identically: the note has to name cryosurgery, electrosurgery, laser, chemosurgery, or curettement, not just state that the lesion was destroyed. For malignant destruction specifically, the note also has to support the malignancy diagnosis driving the code selection and the measured lesion diameter, since both the ICD-10 code and the size bracket are what a payer's medical-necessity review checks first — a malignant destruction code billed against an unspecified skin-cancer diagnosis, or with no diameter documented at all, is one of the more avoidable medical-necessity denials in this family.

Method documentation carries specific weight for cryosurgery in particular: unlike electrosurgery or laser, where the mechanism of destruction is unambiguous from the equipment used, a cryosurgery note that only says "cryotherapy applied" without noting the freeze technique (spray versus probe) or approximate freeze time leaves an auditor asking whether the treatment was aggressive enough to constitute genuine destruction of a malignant or premalignant lesion, versus a superficial treatment more consistent with a benign lesion. Document the technique specifics, not just the modality name.

17110's exclusion of skin tags and cutaneous vascular proliferative lesions is a specificity trap worth naming directly, because both are common same-visit findings that a coder unfamiliar with the exclusion will fold into a benign destruction count by habit. Skin tags (acrochordons) removed by any technique are billed under their own family (11200 for up to 15 lesions, +11201 for each additional 10), not 17110, regardless of how the removal was performed. Cutaneous vascular proliferative lesions — cherry angiomas, pyogenic granulomas treated by destruction, and similar vascular lesions — are also carved out of 17110 and billed under the destruction-of-vascular-lesion codes instead. A visit that treats two actinic keratoses, one skin tag, and one cherry angioma in the same session isn't a single 17110 claim; it's three separate code families, each with its own count logic.

Worked example across the premalignant family: a patient has five actinic keratoses treated by cryosurgery in one session. The claim bills 17000 once (first lesion) plus four units of +17003 (lesions 2 through 5). If that same patient instead had 16 actinic keratoses treated, the claim would drop the per-lesion add-on structure entirely and bill a single unit of 17004, which by definition covers 15 or more lesions in one code — billing 17000 plus thirteen units of +17003 plus 17004 on top would overstate the claim, since 17004 already replaces the entire per-lesion count once the threshold is crossed, not adds to it.

Photodynamic therapy is a distinct, commonly confused family worth flagging separately: when actinic keratoses are treated with a photosensitizing agent activated by a light source rather than physical ablation, that's coded under its own family (application and illumination billed separately from any drug supply code used), not folded into 17000–17004. A practice offering both cryosurgery and PDT for actinic keratosis needs coders who recognize which modality was actually used from the note, since the two are clinically interchangeable treatment options for the same diagnosis but bill under entirely separate code families with different documentation requirements.

Mohs micrographic surgery: 17311–17315

Mohs billing is built around stages and blocks, not the excision-style size brackets used elsewhere in dermatology, and it's the highest-scrutiny procedure family in the specialty because the surgeon is also billing for acting as the pathologist on their own case.

Mohs micrographic surgery codes.
CodeDescription
17311First stage, head, neck, hands, feet, genitalia; up to 5 tissue blocks
+17312Each additional stage after the first, same session, same anatomic location as 17311
17313First stage, trunk, arms, legs; up to 5 tissue blocks
+17314Each additional stage after the first, same session, same anatomic location as 17313
+17315Each additional tissue block beyond the first 5, any stage, either anatomic grouping

Bundled into the Mohs codes: the surgeon's own pathological examination of the tissue removed at each stage (a separate pathology code like 88302–88309 is not billed on top of Mohs for the same specimen, because the Mohs code already includes the surgeon acting as pathologist), and the excision of the tumor itself at each stage. What's separately billable: a diagnostic biopsy performed at a genuinely separate, prior encounter that established the diagnosis before the Mohs procedure was scheduled, and the reconstruction of the resulting surgical defect — a flap, graft, or complex repair — coded using the standard repair codes once the Mohs stages are complete and margins are clear.

The stage-and-block structure works like this in practice: stage 1 removes the visible tumor plus a thin margin, which the surgeon-pathologist processes and examines on-site while the patient waits. If margins are clear, the case ends there and bills as a single stage — 17311 or 17313 alone. If margins are involved, the surgeon removes an additional thin layer only from the specific involved area (not the whole surgical site again) and repeats the process; that's stage 2, billed as +17312 or +17314. Each stage can require more than one tissue block for processing, and the first 5 blocks per case are included in the stage codes — every block beyond that fifth block, regardless of which stage it came from, adds a unit of +17315.

Worked example: a basal cell carcinoma on the nose (head/neck group) requires two stages to clear, with 4 blocks processed at stage 1 and 3 blocks at stage 2 — 7 blocks total. The claim bills 17311 (stage 1) plus +17312 (stage 2) plus +17315 x2 (blocks 6 and 7, since the first 5 are included across the case, not per stage). Getting the block count wrong in either direction is a frequent Mohs billing error — underbilling +17315 units when block counts are high, or billing it against blocks that fall within the included first 5.

Modifier 25 is rarely appropriate on a same-day E/M billed alongside Mohs, because the pre-operative assessment, discussion of the procedure, and post-stage checks are inherent to the global Mohs service itself in the way a pre-procedure assessment is for any other minor procedure — a distinct, unrelated problem addressed the same day is the exception that would support it, not the norm. Reconstruction of the surgical defect is billed once all stages are complete and margins are confirmed clear, using the standard repair, flap, or graft codes on that date of service; billing the reconstruction as though it were part of the Mohs stage codes themselves under-codes what's actually a separately payable service.

A related confusion worth naming explicitly: Mohs is not the same service as a standard excision sent for frozen-section margin control read by a separate pathologist (billed under the frozen-section pathology codes, 88331 and related), even though both involve intra-operative margin assessment. The defining feature of Mohs is that the operating physician personally examines 100% of the surgical margin as their own pathologist, using the specific horizontal frozen-section technique the Mohs codes describe — a excision with a frozen section read by a separate pathologist reviewing only representative margin samples doesn't meet that standard and isn't billable under 17311–17315 regardless of how the case is described colloquially in the chart. Every MAC's Mohs billing-and-coding article draws this line explicitly, because it's the single most common basis for a Mohs claim to fail medical-necessity review on audit.

Two more specificity patterns matter beyond the primary diagnosis crosswalk. First, sequencing when a biopsy result is still pending at the time of the excision or a related visit: bill the symptom or lesion-appearance code (not a presumptive cancer code) until pathology confirms malignancy, then update to the specific C44 code once confirmed. Billing a malignant excision code against an unconfirmed diagnosis, even when clinical suspicion is high, creates a mismatch between the diagnosis and procedure codes that a payer's system can flag independently of whether the excision itself was appropriate. Second, personal and family history codes carry real weight for medical necessity on surveillance visits and repeat full-body exams: a personal history of melanoma or non-melanoma skin cancer, or a documented family history of melanoma, supports the medical necessity of a recurring full-body skin exam in a way symptom-only coding doesn't, and should be carried on every applicable surveillance visit, not just the first one after treatment.

Melanoma coding (the C43 family) follows its own site and staging structure separate from the C44 non-melanoma skin cancer family covered here, and it carries enough independent depth — Breslow depth documentation, sentinel node status, staging-driven treatment planning — that it's treated as its own topic in our ICD-10 specificity spoke rather than folded into the C44 crosswalk above. Merkel cell is rare but aggressive, and billing it under a generic C44 unspecified-malignancy code because C4A isn't on a coder's radar is a real, avoidable specificity error — the diagnosis and the excision or destruction code both need to reflect the correct malignancy type from the start, not get corrected after a payer's medical-necessity review questions why an aggressive-behavior treatment plan is attached to a code that reads as routine skin cancer.

Modifiers that stop dermatology denials: 25, 59, X{EPSU}, 76

Dermatology's modifier logic centers on distinguishing genuinely separate services from routine parts of the same procedure — and getting it wrong in either direction either strips revenue or triggers an audit.

25
  • Significant, separately identifiable E/M on the same day as a minor procedure.
  • Requires distinct history, exam, or MDM beyond what's inherent to the procedure itself.
59 / XE, XS, XP, XU
  • Distinct procedural service — a genuinely separate lesion, structure, encounter, or practitioner.
  • XS (separate structure) covers most defensible dermatology unbundling, since the distinction is almost always anatomic — a different lesion at a different site.
76 / 77
  • 76 — repeat procedure, same physician, same day, genuinely required rather than a continuation of the first attempt.
  • 77 — the same scenario but performed by a different physician, most often relevant when a patient is seen by a covering provider later the same day.
59 on the same lesion
  • Appending 59 or any X-modifier to bill a biopsy and an excision on the same lesion the same session. The record has to show separate lesions or separate encounters — the modifier documents a distinction that has to be clinically real, not one applied to make the claim pass.

Modifier 59 gets specific OIG attention in dermatology because the specialty's high per-visit lesion count creates constant temptation to unbundle routine same-lesion work — a biopsy immediately followed by excision of the same lesion, or multiple destruction passes on what's actually one treatment session for one lesion. Where 59 or an X-modifier is genuinely defensible — two or more separate, distinct lesions treated with different procedures the same visit — XS is almost always the more specific and more defensible choice, because dermatology's distinctions are nearly always anatomic. Modifier 76 covers a legitimate same-day repeat by the same physician (a second destruction pass because the first attempt was technically inadequate), while LT and RT identify laterality on the anatomic sites where ICD-10 also carries a laterality-specific code, keeping the diagnosis and procedure sides of the claim consistent.

Beyond LT/RT, dermatology has access to finger- and toe-specific anatomic modifiers that are frequently underused: FA (left thumb), F1–F4 (left fingers 2 through 5), F5 (right thumb), F6–F9 (right fingers 2 through 5), and the parallel TA/T1–T9 set for toes. On a hand or foot with multiple lesions excised or destroyed the same session, these digit-specific modifiers do the same job XS does at a coarser level — they state precisely which distinct anatomic site each line item covers, which both supports separate payment and heads off an MUE or duplicate-service review before it starts. Eyelid excisions and destructions have their own quadrant-specific set (E1 upper left, E2 lower left, E3 upper right, E4 lower right) that functions the same way. Skipping these on a multi-digit or multi-lesion eyelid claim in favor of a generic X-modifier is technically defensible but invites more scrutiny than the more specific code would.

Modifier 51 (multiple procedures) shows up less often in dermatology than the anatomic and distinct-service modifiers, and it's worth clarifying why: Medicare's own claims processing applies the multiple-procedure payment reduction automatically based on the codes billed, without requiring 51 to be appended, and most Medicare Administrative Contractors explicitly instruct against appending it. Some commercial payers still expect it on multi-procedure claims per their own claims-submission rules, which makes 51 one of the few modifiers in this specialty where the correct answer is genuinely payer-specific rather than governed by a single national rule — check the payer's own claims guide rather than applying it uniformly across your whole payer mix.

Modifier 58 covers a scenario specific to excision follow-up: a staged or related procedure performed by the same physician during the excision's post-operative global period. The most common dermatology trigger is a re-excision after a pathology report comes back with positive or narrow margins — the second excision is planned as a direct result of the first, performed by the same physician, during the original procedure's global period, which is exactly what modifier 58 is built for. Billing the re-excision without it, or without recognizing that the first excision's global period is still open, is a common source of a claim denying as though it duplicated the original procedure rather than being correctly recognized as a staged, related second surgery.

Worked multi-modifier scenario: a visit treats three actinic keratoses on the face by cryosurgery and biopsies a fourth, clinically distinct pigmented lesion on the same visit, with a documented, separately identifiable discussion of a new atopic dermatitis flare. That claim carries an E/M with modifier 25 (the dermatitis discussion, separately identifiable from the procedures), the destruction code for the three AKs (17000 plus two units of +17003), and the biopsy code for the fourth lesion with an X-modifier (XS, separate structure) distinguishing it from the destroyed lesions. Three modifiers, three different jobs — 25 separates the E/M from the procedures, XS separates the biopsied lesion from the destroyed ones, and neither modifier does the other's job.

NCCI edits and MUE limits in dermatology

Two values decide whether a bundled or capped dermatology code is billable at all, and neither is a judgment call — both are pair-specific and code-specific values CMS publishes and updates quarterly.

The NCCI modifier indicator attached to a Column 1/Column 2 code pair:

  • 0Never bypassable. No modifier overrides it, however well the record documents a genuine distinction. If the biopsy-into-excision pair on the same lesion carries a 0, the biopsy simply isn't separately payable.
  • 1Bypassable with documentation. An NCCI-associated modifier (59 or the specific X-modifier) can override the edit, but only where the record shows the second service was genuinely distinct — a different lesion, a different site, a different session.
  • 9Edit deleted. The pair no longer applies; the indicator itself carries no meaning going forward.

Where this shows up most in dermatology: the biopsy-into-excision edit on the same lesion (CPT's own correct-coding guidance already says code the excision only in that scenario, and NCCI mirrors it), destruction billed the same day as an E/M without a distinct, separately documented reason for the E/M, and excision paired with a repair code where the repair's complexity doesn't clear the bar for separate billing. The pair-specific modifier indicator is what determines whether any of these can ever be split apart with a modifier — documentation alone doesn't decide it if the indicator itself is 0.

The excision-into-repair edit deserves its own callout because it's structural, not a documentation question at all: simple closure is bundled into the excision code by CPT definition, full stop, and no modifier — 59, an X-modifier, or anything else — makes a simple closure separately billable on top of an excision. The only way a repair becomes separately payable is for it to genuinely meet the intermediate or complex repair definition (layered closure, extensive undermining, retention sutures, or reconstruction), at which point it's not an edit override at all — it's simply a different, separately-coded service that was never bundled with the excision in the first place. Confusing "the repair denied" with "I need a modifier to unbundle it" sends staff down the wrong path; the actual question is whether the repair performed meets the complexity threshold for its own code.

Understanding which code sits in Column 1 and which sits in Column 2 of an NCCI pair matters for how you read a denial, not just for how you appeal it. The Column 1 code is the one CMS considers the comprehensive, more extensively valued service — the excision, in the biopsy-into-excision pair — and the Column 2 code, the biopsy, is the one that's disallowed as a separate line when both are billed for the same encounter. A remittance that denies the Column 2 code isn't saying that service wasn't performed or wasn't necessary; it's saying CMS has already valued it as included in the Column 1 code's payment. That distinction matters when a physician or biller pushes back on a bundling denial as though the payer is disputing medical necessity — it isn't, in an NCCI bundling denial specifically; it's a payment-methodology decision that predates the claim entirely.

The MUE Adjudication Indicator (MAI) attached to a per-code, per-day unit cap works the same way it does across every specialty:

  • 1Claim-line edit. Units above the cap deny that line, but genuinely repeated, distinct procedures can often be split across separate lines with the correct modifier and documentation.
  • 2Absolute, date-of-service edit. CMS treats exceeding it as clinically implausible. No appeal path exists — confirm the MAI before staff time is spent writing one.
  • 3Appealable, date-of-service edit. A real path exists with documentation showing the excess units reflect genuinely distinct, medically necessary work — more plausible in dermatology than in most specialties, given how many lesions a single visit can legitimately treat.

High-volume dermatology codes like 11102 and 11104 carry per-day MUE caps precisely because a single biopsy base code should appear once per session (additional lesions use the add-on codes, not repeated units of the base code) — a claim with multiple units of the base biopsy code itself, rather than units of the add-on, is a common and avoidable MUE trip point.

Worked scenario: a claim comes back denied on 17111 (destruction, 15 or more benign lesions, add-on) with a bundling reason code against 17110. Before assuming it's a straightforward bundling denial, confirm two things in order — first, that 17111 was actually billed as an add-on to a 17110 line on the same claim (a 17111 billed without its required base code 17110 present will deny regardless of medical necessity, since it's structurally an add-on, not a standalone code); second, if both are present and it's still denying, check whether the total lesion count crossed 14 in a way the documentation supports. Most "bundling" denials in this specific pair turn out to be a missing base-code line item, not a genuine NCCI edit — a five-minute claim-form check that resolves faster than a formal appeal.

Before appealing a CO-50 cosmetic reclassification, attach a clinical photo whenever one exists in the chart. An Advance Beneficiary Notice heads off a CO-50 dispute before it happens on Medicare claims where the lesion's cosmetic-versus-medical status is genuinely ambiguous at the time of service — a lesion the patient wants removed that doesn't clearly meet a covered indication yet. A CO-50 cosmetic-reclassification appeal opens strongest when it leads with the objective finding, not the treatment rationale: "The lesion excised on [date] measured 1.4cm with irregular borders and a documented two-month history of bleeding on contact, findings recorded in the [date] office visit note attached. Pathology confirmed [diagnosis]. The attached clinical photograph, taken prior to excision, documents the irregular border and surface change referenced in the visit note." That structure — objective measurement, documented symptom history, pathology confirmation, and a photo where one exists — gives the reviewer a concrete basis to reverse a cosmetic flag instead of a narrative argument alone. A bare statement that the excision "was medically necessary" without those specifics rarely moves a reviewer who's already flagged the claim once.

CO-151 frequency denials in dermatology most often hit destruction and re-excision claims where a payer's system flags a repeat procedure on the same or an adjacent body area within a short window as a probable duplicate, even when the second treatment targets a genuinely different lesion or represents a legitimate re-treatment of a lesion that recurred or responded incompletely. The fix is the same either way: confirm what interval and what documentation the specific payer requires to support a second treatment in the same area, attach the note distinguishing the second procedure from the first (different lesion, incomplete response, recurrence), and rebill or appeal accordingly rather than assuming the denial reflects an actual duplicate billing error.

Know which appeal level you're actually filing before you start. A first-level appeal (often called redetermination on the Medicare side) is where a corrected-claim-eligible error or a straightforward documentation gap gets resolved fastest, and it's where the vast majority of CO-97 and CO-4 issues should be resolved. A second-level appeal (reconsideration) is worth reserving for claims where the first-level response upheld the denial and the underlying medical-necessity argument genuinely needs a fresh, more detailed record — typically CO-50 cosmetic reclassifications that survived the first appeal. Filing a full second-level-style appeal packet for what's actually a first-level correction wastes staff time the claim didn't need spent.

Payer coverage nuances: teledermatology and skin substitutes

Medicare's teledermatology coverage is narrower than a lot of guides in this space imply, and the gap between what's actually covered and what practices assume is covered is one of the more expensive misunderstandings in the specialty. Store-and-forward teledermatology — a dermatologist reviewing a submitted photograph asynchronously, without a live encounter — is covered by Medicare nationally only inside the federal telehealth demonstration programs operating in Alaska and Hawaii, authority that traces back to BIPA provisions from 2001 and has not been broadened nationally. Outside those two states, a photo-only, asynchronous dermatology consult is not a covered Medicare telehealth service, regardless of how clinically appropriate the review is.

A real-time video visit is a different service entirely and follows Medicare's standard telehealth rules for E/M services — live audio-video with the patient present, billed the same way any other telehealth E/M is billed under the current telehealth code list and place-of-service rules. The confusion between the two models — treating "we did a video visit" and "we reviewed a photo" as interchangeably covered — is where practices get exposed, because only one of them is a nationally covered Medicare benefit outside Alaska and Hawaii.

ModelMedicare coverage

State Medicaid programs and commercial payers vary widely on store-and-forward coverage — several states reimburse it under their own Medicaid telehealth policy even where Medicare doesn't nationally, and commercial payer coverage is contract-specific. Never assume Medicare's restriction applies to a Medicaid or commercial claim, and never assume a state Medicaid store-and-forward benefit extends to Medicare. Confirm the specific payer's own teledermatology policy before building a workflow around either model. Where a practice runs both a Medicare and a commercial or Medicaid patient panel through the same asynchronous photo-triage workflow, the safest operational default is to route the Medicare population to a real-time visit model exclusively, and reserve the store-and-forward workflow for the payers whose policy has actually been confirmed to cover it — building one workflow and assuming it applies uniformly across payers is the most common source of exposure here.

Skin substitute and cellular tissue product billing sits in the same section because it's the other place dermatology practices get tripped up by a payment-methodology change rather than a coding one: the CY2026 OPPS/ASC final rule (CMS-1834-FC) moved most skin substitutes from ASP-based reimbursement to a flat per-square-centimeter rate, sorted into three new APCs by FDA regulatory pathway — APC 6000 for premarket-approval products, APC 6001 for 510(k)-cleared devices, and APC 6002 for Section 361 human cell and tissue products — with products licensed as biologics under Section 351 of the Public Health Service Act remaining on the ASP methodology outside this restructuring. ⚠️ The specific flat-rate dollar figure for 2026 could not be confirmed to a single number during this build — reported between $127.14 and $127.28 per cm² depending on the source — so confirm the current rate against the CMS OPPS/ASC final rule directly before billing a skin substitute application under it.

⚠️ This restructuring is explicitly framed around outpatient prospective payment (hospital outpatient departments and ASCs) in every source reviewed for this build; how it maps onto a skin substitute applied in a physician's office and billed under the Medicare Physician Fee Schedule rather than OPPS/ASC could not be confirmed here and should be checked directly against your MAC or the final rule before assuming the same flat rate applies to non-facility billing. This affects wound-care and chronic ulcer applications far more than routine lesion work, but any dermatology practice applying cellular tissue products in any setting should confirm which payment methodology applies to that specific site of service.

Beyond Medicare's own restructuring, commercial payer and Medicaid managed-care coverage of skin substitutes varies independently of the federal payment methodology — a product covered under a specific APC for a Medicare claim may sit on an entirely different prior-authorization or step-therapy requirement for a commercial plan, particularly for chronic wound applications where payers increasingly require documented failure of standard wound-care measures before authorizing a cellular tissue product at all. Verify the specific payer's own coverage policy and any required step-therapy documentation before the first application, not after a claim built around several planned applications starts denying partway through the treatment course.

Prior authorization: biologics and staged procedures

Biologic prior authorization for psoriasis, atopic dermatitis, and hidradenitis suppurativa is documentation-heavy and diagnosis-specific in a way that rewards getting the ICD-10 code right before the request is ever submitted. Payers consistently require a specific subtype code — not unspecified — plus documented failure or intolerance of conventional treatment before approving a biologic.

  • 1Psoriasis biologics. Require a specific subtype code (L40.0 plaque, L40.1 generalized pustular, L40.4 guttate, or the arthropathic codes under L40.5- when joint involvement drives the request), plus documented failure, intolerance, or contraindication to at least one conventional systemic agent or phototherapy course, with dates and outcomes.
  • 2Atopic dermatitis biologics. Require the specific atopic dermatitis code (L20.89 or the appropriate subtype), body surface area or validated severity-score documentation, and step-therapy evidence of failed topical and, frequently, prior systemic treatment.
  • 3Hidradenitis suppurativa biologics. Diagnosis is straightforward — L73.2 is the single code, no subtype specificity required — but payers scrutinize disease-stage documentation (Hurley staging) and prior antibiotic or conventional-therapy failure heavily, so the diagnosis code being simple doesn't mean the request is.

Unspecified diagnosis codes are one of the fastest routes to a prior-auth denial in this category, because the reviewer's first check is often automated and rejects on code specificity before the clinical failure history is ever read by a person. Build the specific subtype code into the order set at the point the biologic is prescribed, not after the first denial comes back.

Step therapy documentation has to be structured, not narrative, to clear most payers' automated review: the request needs the specific conventional agent tried (not "topical steroids" generically, but the actual drug and strength), the dates of the trial, the duration, and the documented outcome (inadequate response, intolerance, or a specific adverse reaction). A note that says "failed conventional therapy" without naming the agent and dates reads to most utilization-management systems the same as no step-therapy documentation at all. Where a patient has a documented contraindication to first-line conventional therapy rather than a failed trial — a contraindicated topical due to a comorbid condition, for example — that contraindication needs to be stated explicitly and tied to the specific agent it rules out, not left implicit.

When a biologic prior authorization is denied despite complete step-therapy documentation, a peer-to-peer review — the prescribing physician speaking directly with the payer's reviewing physician, rather than staff resubmitting the same paperwork — resolves more denials than a written appeal alone, particularly where the denial reason is a clinical judgment call (severity threshold, adequacy of the conventional trial) rather than a missing document. Request the peer-to-peer promptly once a denial is confirmed rather than defaulting straight to a written appeal; most payers set a narrow window to request it, and missing that window forces the slower written-appeal path for a denial that a ten-minute physician conversation might have resolved.

Staged procedures carry their own precert exposure. Several commercial payers require prior authorization for Mohs surgery and for staged excisions with complex reconstruction, particularly where the anticipated repair involves a flap or graft rather than a simple or intermediate closure. The peri-procedure denial risk here is specific: authorization obtained for the excision or Mohs stages doesn't automatically cover the reconstruction that follows if the payer's precert policy treats them as separate authorizable events. A common failure pattern: a practice obtains authorization for "Mohs surgery, right cheek lesion" and proceeds, but the case requires a rotation flap for reconstruction that the payer's authorization never contemplated — the flap billed under a separate repair code denies for lack of authorization even though the underlying Mohs procedure was properly authorized and performed. Confirm whether your payer mix requires separate authorization for the reconstruction phase before scheduling a staged case, not after the defect is already open, and where reconstruction complexity can't be predicted in advance, confirm the payer's process for expedited or retroactive authorization on the anticipated closure method before the case is booked.

Get dermatology billing that doesn't leave revenue on the table

Dermatology's revenue leaks in small amounts across a high volume of claims rather than in a few large denials, which is exactly what makes it hard to catch without deliberately auditing for it. A biopsy billed as a duplicate unit instead of the correct add-on code, a repair that should have been billed separately but got folded silently into the excision, a Mohs claim missing a block-count unit, a cosmetic flag that never gets appealed because the photo that would reverse it was never attached — none of these show up as a single dramatic loss. They show up as a revenue cycle that's consistently a few percentage points below what the practice actually earned, spread across thousands of claims where no single one looks wrong enough to investigate on its own.

The fixes in this guide are specific on purpose: seven named Mohs LCD articles instead of "check your MAC," a full excision-and-repair size table instead of a prose range, the NCCI modifier indicator that actually decides whether a bundling edit can be overridden, and the exact appeal argument that reverses a cosmetic reclassification. If your practice is seeing denial patterns that match what's described here — or if nobody's checked recently whether they match — that's the conversation worth having before the next batch of claims goes out.

Frequently asked questions

Why do we get denied when we bill a biopsy and an excision on the same lesion the same day?

CPT's own correct-coding rule, mirrored in the NCCI biopsy-into-excision edit, says the biopsy is a component of the excision when both are performed on the same lesion at the same session — code the excision only. The edit's modifier indicator does allow an override in limited situations, but only when the biopsy and excision genuinely happened on separate, distinct lesions or at separate encounters, and only with clear documentation of that separation. Appending 59 or an X-modifier to bill both on the same lesion the same day is exactly the pattern payers audit for.

Do we really have to name the destruction method on every claim now?

Yes. Destruction codes 17000–17004 and 17110–17111 have always allowed any standard method — cryosurgery, electrosurgery, laser, chemosurgery, curettement — but a note that just says "lesion destroyed" no longer supports the code on audit. Document the specific method, the lesion type (premalignant vs. benign vs. malignant), the count, and the site for every destruction claim, or expect the claim to survive submission but fail a records request.

Does Medicare cover a photo-only teledermatology consult?

Only inside the federal telehealth demonstration programs in Alaska and Hawaii. Nationally, Medicare does not reimburse asynchronous store-and-forward teledermatology — a dermatologist reviewing a submitted photo without a real-time encounter — outside those two demonstration states. A live, real-time video visit is a different service entirely and bills as standard telehealth E/M under Medicare's usual telehealth rules. Commercial payers and state Medicaid programs vary widely on store-and-forward coverage, so check the specific payer before assuming either model is covered.

Which MAC's Mohs LCD applies to our practice?

Whichever Medicare Administrative Contractor holds your practice's jurisdiction — Mohs coverage is local, not national, and seven MACs each publish their own billing-and-coding article: Novitas Solutions (A53883), Palmetto GBA (A56732), WPS Insurance Corporation (A57477), CGS Administrators (A56836), Noridian Healthcare Solutions (A56514), and First Coast Service Options (A57767). Pull your own MAC's article by name before building a medical-necessity checklist — a generic "Mohs is covered when medically necessary" summary from a competitor's guide isn't tied to any specific contractor's requirements.

Is modifier 59 or an X-modifier better for two lesions destroyed in the same session?

XS (separate structure) is almost always the more defensible choice in dermatology, because the distinction is nearly always anatomic — a separate lesion at a separate site. Generic 59 works but doesn't state why the services were distinct, while XS does that on the face of the claim. Either way, the edit's modifier indicator has to allow an override in the first place — an indicator of 0 means no modifier changes the outcome regardless of how distinct the lesions actually were.

What ICD-10 specificity does a biologic prior authorization for psoriasis actually require?

Most commercial payers and Part D plans require a specific psoriasis subtype code — plaque (L40.0), generalized pustular (L40.1), guttate (L40.4), or the arthropathic codes (L40.5-) when joint involvement drives the request — rather than unspecified psoriasis (L40.9), plus documented failure or intolerance of at least one conventional systemic or phototherapy option. An unspecified diagnosis code is one of the fastest ways to trigger a prior-auth denial before the clinical failure history is even reviewed.

What changed in dermatology CPT coding for 2026?

The biggest operational change is a documentation mandate, not a code deletion: biopsy codes 11102–11107 and destruction codes 17000–17004 and 17110–17111 now require the specific technique or method to be named in the note — tangential, punch, or incisional for biopsies; cryosurgery, electrosurgery, laser, or chemosurgery for destructions. The codes themselves didn't change, but a chart that only says "biopsy performed" or "lesion destroyed" no longer supports the code on audit. Separately, most skin substitute and cellular tissue products moved from ASP-based payment to a flat per-square-centimeter rate under the CY2026 OPPS/ASC final rule (CMS-1834-FC). The exact 2026 flat rate could not be confirmed to a single dollar figure during this build — secondary sources reported it between $127.14 and $127.28 per cm² — so confirm the current rate against the CMS final rule or your MAC before billing against it.
