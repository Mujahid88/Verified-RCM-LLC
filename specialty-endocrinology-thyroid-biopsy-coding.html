Thyroid biopsy and FNA coding: image-guided vs. open procedures.

A thyroid nodule biopsy claim gets denied for one of three predictable reasons: the wrong FNA code for the guidance actually used, an ultrasound-guidance code billed on top of one that already includes it, or a diagnosis that never got updated once the cytology came back. This guide walks the full code family, ultrasound-guided FNA (10005/10006), non-guided FNA (10021/10004), the percutaneous core-needle step up (60100), the pathology codes billed on a separate claim entirely, and the ICD-10 progression from a working diagnosis to a confirmed one.

Key takeaways

  • The code depends on guidance, not just the lesion. Ultrasound-guided FNA is 10005 (first lesion) and 10006 (each additional lesion, add-on); FNA done without any imaging guidance is 10021 and 10004. Since the 2019 CPT restructuring, these are separate code families, not one code plus a guidance modifier.
  • Ultrasound guidance is bundled into 10005/10006, it cannot be billed again as 76942 for the same lesion. That pairing is an NCCI unbundling edit, and it's the single most common denial on a thyroid FNA claim.
  • 60100 is a percutaneous core-needle biopsy, not an open surgical biopsy. There is no dedicated CPT code for a true open/incisional thyroid biopsy; it reports as an unlisted endocrine procedure (60699) on the rare occasion it happens at all.
  • The biopsy and the cytology read are two different claims. The practice bills the collection code; the pathologist or reference lab bills the interpretation (88172/88173, or 88305 for a core specimen) separately, often under a different NPI entirely.

The FNA code family: the guidance used decides the code, not just the lesion count

Before January 1, 2019, thyroid FNA coding was simple to the point of being imprecise: 10021 for FNA without imaging guidance, 10022 for FNA with imaging guidance of any kind. The AMA CPT Editorial Panel deleted 10022 entirely and replaced it with nine modality-specific codes (10004–10012), so the guidance modality itself now determines which code family applies. For thyroid nodules, a small, deep, vascular structure, ultrasound guidance is the modality used in the overwhelming majority of office and radiology-suite FNAs, which makes 10005/10006 the codes billed most often in this specialty.

Fine needle aspiration biopsy codes relevant to thyroid nodules, current CPT code set.
CodeDescriptor (paraphrased)GuidanceLesion position
10005Fine needle aspiration biopsy, including ultrasound guidance; first lesionReal-time ultrasound, bundled into the codeFirst lesion
10006Fine needle aspiration biopsy, including ultrasound guidance; each additional lesion, same session (add-on)Real-time ultrasound, bundled into the codeEach additional lesion
10021Fine needle aspiration biopsy, without imaging guidance; first lesionNoneFirst lesion
10004Fine needle aspiration biopsy, without imaging guidance; each additional lesion, same session (add-on)NoneEach additional lesion

Two coding details matter more than they look like they should on a thyroid claim. First, 10004 and 10006 are billed once per additional lesion sampled, not once per needle pass through the same lesion, multiple passes to get adequate cellularity on one nodule is still one unit. Second, when a single session mixes guidance modalities for genuinely different lesions (rare for thyroid alone, more common when a thyroid nodule and a separate neck node are both sampled), each modality's primary code is reported with modifier 59 or the appropriate X{EPSU} modifier to show they're distinct procedures, not a duplicate billing of the same lesion.

When FNA isn't enough: the core-needle step up, and what "open biopsy" actually means

An FNA result that comes back non-diagnostic (Bethesda category I, insufficient cellular material) or persistently indeterminate is the usual trigger for a percutaneous core-needle biopsy, reported with CPT 60100. This is worth being precise about, because a lot of secondary billing content shorthands 60100 as "open thyroid biopsy," and that's not what the code describes.

Thyroid tissue-sampling procedures by needle type and what each one actually captures.
CodeWhat it capturesNeedle typeWhen it's used
10005/10006Cells, for cytologyFine (thin-gauge) needleFirst-line workup of a sonographically suspicious nodule
60100An intact tissue core, for histologyLarger, spring-loaded core needle, percutaneousFNA came back non-diagnostic or repeatedly indeterminate
60699 (unlisted)Surgically obtained tissue, for histologyN/A, open/incisional surgical approachTrue open biopsy; no dedicated CPT code exists, so this reports as an unlisted endocrine system procedure

⚠️ The bundling rule that only 60100 is reported when a core-needle biopsy follows an FNA attempt at the same encounter is documented consistently across coding-education sources (AAPC discussion threads, coder training material); it was not independently confirmed against a live NCCI Procedure-to-Procedure edit lookup in this build. Verify the current-quarter NCCI PTP table for the 10005/10021-to-60100 pairing before relying on it for a specific denial appeal.

A true open (incisional or excisional) biopsy of thyroid tissue via a surgical approach, as opposed to a percutaneous needle, however large the bore, has no CPT code of its own. It reports as 60699, unlisted procedure, endocrine system, which means the claim needs a cover letter comparing the work to a similarly-valued listed procedure and the operative note attached, because the payer has no fee schedule line to price it against automatically. In practice this scenario is uncommon: a nondiagnostic core-needle result more often leads straight to diagnostic lobectomy (a listed, separately coded procedure) than to a standalone open biopsy step.

The recurring denial: billing guidance that's already bundled

The single most common reason a thyroid FNA claim comes back denied or downcoded isn't a wrong diagnosis or a missing modifier, it's billing 76942 (ultrasound guidance for needle placement) on the same date, same lesion, as 10005. That pairing made sense under the pre-2019 code set, when 10022 didn't include guidance and 76942 was reported alongside it to capture the imaging work. It doesn't make sense under the current code set, because 10005's own descriptor already reads "including ultrasound guidance", the guidance work is priced into the code's relative value units, not held out separately.

Billable together
  • 76942 on the same date as 10005, only when the guidance documents a separate, distinct procedure on a different structure, for example, ultrasound-guided biopsy of an adjacent lymph node coded separately from the nodule FNA. Append modifier XS and keep the two procedures' documentation clearly separated in the note.
Not billable together
  • 76942 and 10005 for the same nodule at the same session. The guidance used to place the needle in that nodule is the guidance the 10005 descriptor already accounts for, billing it again is reporting the same work twice, and it will be caught by an NCCI procedure-to-procedure edit.

The fix on the front end is a coding rule, not an appeal: if the ultrasound guidance and the needle biopsy were the same act on the same nodule, one code (10005 or 10006) carries the whole encounter. Save 76942 for the sessions where it's genuinely a separate, identifiable service.

Pro tip

When the FNA sample goes to an outside reference lab, confirm before the visit whether that lab bills the patient's insurance directly or bills the ordering practice, which then bills the payer. Both arrangements exist, and getting it backwards is how a practice ends up with an unbillable pathology charge sitting on its books, or a patient billed twice for the same cytology read from two different entities.

Pathology coordination: the biopsy claim and the cytology claim are separate

Whoever performs the aspiration, endocrinologist, radiologist, or surgeon, bills the collection code. Whoever reads the slides bills the interpretation, on its own claim, frequently under a different tax ID and NPI entirely, especially when the sample is sent to an outside cytopathology lab rather than read in-house.

Cytopathology and surgical pathology codes associated with thyroid biopsy specimens, and who typically bills each one.
CodeWhat it coversTypically billed by
88172On-site cytohistologic adequacy assessment during the procedure, first evaluation episodeThe cytotechnologist or pathologist physically present at the biopsy, only if that immediate on-site check actually happens
88173Cytopathologic interpretation of the fine needle aspirate (the definitive read, reported after the procedure)The interpreting pathologist or reference laboratory, on its own claim
88305Surgical pathology, gross and microscopic examination (Level IV), used for a core-needle or open tissue specimen rather than an FNA smearThe interpreting pathologist or lab reading the 60100 core specimen

88172 is easy to over-bill: it requires a cytotechnologist or pathologist physically present at the time of collection, actively determining in real time whether the sample is adequate before the patient leaves. A slide reviewed later that day by the same person doesn't qualify, that's simply part of the 88173 interpretation. Most office-based thyroid FNAs skip the on-site adequacy check and go straight from collection to a mailed specimen and a next-day 88173 read; 88172 shows up mainly in radiology-suite or academic settings with cytopathology staff on hand.

Bethesda categories: what drives the next coding decision

The cytology report doesn't just say "benign" or "malignant" in isolation, it assigns one of six standardized Bethesda System categories, each carrying an accepted risk-of-malignancy range that determines whether the next step is routine surveillance, molecular testing, repeat biopsy, or surgical referral. The system was most recently updated in its third edition (2023), which refined the risk-of-malignancy estimates and split the atypia-of-undetermined-significance category into two subgroups.

ICD-10 coding: from working diagnosis to confirmed result

The diagnosis on a thyroid biopsy claim should reflect what's actually known at the time of the encounter, not a placeholder that never gets revisited once pathology reports back.

ICD-10-CM codes commonly used across a thyroid nodule workup, verified current and valid for HIPAA transactions (FY2026 code set).
CodeDescriptionWhen it applies
R94.6Abnormal results of thyroid function studiesWorking diagnosis before a nodule is characterized on imaging, supports medical necessity for the initial workup
E04.1Nontoxic single thyroid noduleSolitary nodule identified on ultrasound or exam, no hyperthyroidism
E04.2Nontoxic multinodular goiterMultiple nodules identified; the one biopsied should be specified in the note by size and location
E04.9Nontoxic goiter, unspecifiedDocumented goiter without further nodule specificity, use only when the record genuinely doesn't support E04.1 or E04.2
D34Benign neoplasm of thyroid glandAfter a Bethesda II (benign) result, when the finding is coded as a benign neoplasm rather than a simple nodule
C73Malignant neoplasm of thyroid glandAfter a Bethesda VI (malignant) result, or a V result confirmed surgically

E04.9 is the code worth watching on outgoing claims, the same way an unspecified code is a flag anywhere else in ICD-10: if the ultrasound report already documents a single dominant nodule with measurements, E04.1 is the more specific and more defensible code, and payers increasingly scrutinize unspecified codes when a more specific one was clearly available in the chart.

Worked example: ultrasound-guided FNA of a single thyroid nodule, outside lab reads the cytology

A patient presents with a single 1.8 cm thyroid nodule found on prior imaging. The endocrinologist performs an in-office ultrasound-guided FNA of the one nodule and sends the sample to an outside cytopathology lab. No on-site adequacy check is performed. The lab's report comes back Bethesda II, benign.

Code sequence for the worked example, split by which entity bills which claim.
Who billsCode(s)DiagnosisNotes
Endocrinology practice10005 ×1E04.1Single lesion, ultrasound guidance bundled, do not add 76942
Outside cytopathology lab88173E04.1 (or the lab's own working code per its requisition)Billed on the lab's own claim, separate NPI, days after the specimen is received
Endocrinology practice, follow-up visitE/M code per documented levelE04.1 (Bethesda II confirmed benign)Diagnosis stays E04.1; no change to D34 needed since the result was benign, not a coded neoplasm

If the same scenario instead came back Bethesda VI (malignant), the practice's own subsequent claims, the follow-up visit, the surgical referral, any pre-operative workup, update to C73, and the FNA claim itself is not resubmitted or recoded retroactively; the diagnosis on file at the time of the biopsy (E04.1, a nodule not yet characterized as malignant) was accurate for that date of service. The most frequent error in this exact scenario is the practice appending 76942 to the 10005 line because a coder unfamiliar with the 2019 restructuring assumes guidance is always billed separately, that claim line denies as bundled, and correcting it means dropping 76942 entirely rather than appealing for separate payment.

Frequently asked questions

Can ultrasound guidance (76942) be billed separately from a thyroid FNA (10005)?

No. Since the January 1, 2019 CPT restructuring of the FNA code family, real-time ultrasound guidance is bundled into 10005 (first lesion) and 10006 (each additional lesion, same session), the descriptor itself reads "including ultrasound guidance." Reporting 76942 alongside 10005 for the same lesion is an NCCI unbundling edit and denies as included in the primary procedure. The only time 76942 is separately payable on the same claim is when it documents guidance for a genuinely different procedure, for example an ultrasound-guided lymph node core biopsy performed at the same encounter, supported with modifier XS and its own operative note.

What's the difference between CPT 10005 and CPT 60100 for a thyroid biopsy?

10005 is a fine needle aspiration, a thin needle draws cells for cytology, reported with ultrasound guidance bundled in for the first lesion. 60100 is a percutaneous core needle biopsy, a larger, spring-loaded needle removes an actual tissue core for histology, typically ordered when a prior FNA came back non-diagnostic (Bethesda I) or indeterminate. They are not both reportable for the same lesion at the same encounter; when a core needle biopsy follows an FNA attempt in one session, only 60100 is billed. Neither code describes a true open surgical biopsy, which has no dedicated CPT code and is reported as an unlisted endocrine procedure (60699) when it occurs at all.

Who bills the cytopathology interpretation when a thyroid FNA sample goes to an outside lab?

The pathologist or reference laboratory that reads the slides bills the interpretation, typically 88173 for cytopathologic evaluation of the fine needle aspirate, on its own claim, under its own NPI, separate from the practice's biopsy claim. The practice or physician performing the aspiration bills only the collection code (10005/10006 or 10021/10004). If a cytotechnologist or pathologist is physically present during the procedure to check specimen adequacy in real time, that on-site adequacy assessment is reported separately as 88172, again by whoever performed it, rarely the collecting practice unless it employs its own cytopathology staff.

Which ICD-10 code goes on a thyroid FNA claim before the pathology results come back?

Code to the most specific finding already confirmed by imaging or exam at the time of the biopsy, E04.1 for a documented solitary nontoxic nodule, E04.2 for multinodular goiter, or E04.9 when the goiter isn't further specified. If the biopsy is being done to work up an abnormal thyroid function test or imaging finding that hasn't yet been characterized as a nodule, R94.6 (abnormal results of thyroid function studies) supports medical necessity for the encounter. Once the Bethesda category comes back, update the diagnosis on the next claim in that episode of care, D34 for a benign result, C73 if malignancy is confirmed, rather than leaving a placeholder code on file indefinitely.
